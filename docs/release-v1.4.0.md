# Card Vault v1.4.0

版本：1.4.0；日期：2026-10-13。本版完成“寻卡”与首页收藏概览，保留现行财务规则。详细操作见[寻卡指南](./scout-guide.md)，提交内容见 [Git 更新说明](./git-update-v1.4.0.md)。

## 功能

- 首页按估值、卡片、收藏概览并列展示，统一字号与对齐；状态数量可筛选。概览显示新增、出售、估值与待整理，7/30 天周期静默保存，整理明细按需分页并支持撤销。
- 跨站查询提供卡淘、eBay、130 Point 官方 Logo 入口和独立复制按钮。已保存关键词采用分隔列表，支持筛选、复用、折叠、跨页选择、批量删除和 CSV 导出。
- 心愿支持搜索排序、优先级、预算、多个关联关键词及可选目标数量。新卡录入与已有卡片多选绑定都可更新进度；普通心愿直接完成，有目标的心愿保留部分进度并在达到目标后实现。
- 多卡选择器支持搜索、分页、仅看已选、折叠与增减摘要，最多绑定 500 张。已入藏记录可更换，查看关联卡片进入首页；卡片详情提供返回心愿入口。
- 重新计划或取消会说明解除绑定的影响并提供 30 秒撤销。心愿草稿按收藏保存在本机，筛选、分页与展开位置按窗口会话恢复；提交失败保留输入，提交成功后刷新失败只重试读取。
- 关键词与心愿可分别导出完整 CSV 清单；绑定详情按需加载。多词搜索支持在不同卡片字段中匹配。

关键词仅包含查询文本与心愿关系；商品、价格、研究记录、关键词编辑和状态管理已删除。本版不包含后台采集、自动更新、到价提示或多设备同步。

## 代码整理

全面扫描应用、组件、业务库、Electron 和脚本中的源码，按实际职责整理：

- 组合聚合分为财务、分组和历史模块，财务计算分离币种及估值投影；保留独立冻结对照实现。
- 卡片和寻卡导出共用 `export-workspace`，统一一致性快照、两任务并发额度、超时、下载取消与临时文件清理。
- 首页概览和单条整理操作共用 `collection-task-service`，仅读取所需字段和最近有效估值。
- 移除旧计划读写入口，心愿写入集中在 `/api/scout`，概览读取集中在 `/api/home-overview`。
- 合并心愿定位分页逻辑，校验恢复状态，防止旧请求或旧存储范围覆盖当前数据。
- 寻卡样式集中在 `app/styles/scout.css`；删除旧计划样式及已撤销功能的翻译，合并重复更新说明。

## 数据与文档

寻卡包含 `ScoutWatch`、`ScoutWishDetails`、`ScoutWishWatch`、`ScoutWishCard` 四表。完整 v1.3 基础格式扩展前创建 SQLite 一致性快照，事务新增结构；恢复旧基础格式只扩展暂存副本。残缺结构和不受支持的更早格式拒绝写入。完整备份覆盖四表；浏览器草稿不属于完整备份，CSV 不能替代完整备份。详见[备份规则](./data-backup-guide.md)。

双语 README、应用内说明、文档索引、路线图、主题、分享、数据管理、财务及备份规范已同步。历史发布文档保留当时事实；部分旧发布文件来自另一台电脑，Git 同步源码与发布文件来源分别记录。
