# Card Vault 代码审核与整理

审核日期：2026-09-07。源码版本 v1.3.0。本文件将首次评估的问题与累计修改后的处理结果合并，当前验收以[开发进度](./v1.3.0-implementation.md)为准，不再将修复前的失败当成现状。

## 范围与方法

对 app、components、lib、electron、scripts、tests、Prisma 模型、CI 和全部项目 Markdown 进行目录、依赖、导出符号、重复实现、失效样式和文档一致性检查。开始时有 336 个代码/样式文件，约 3.8 万行，统计不包含依赖、构建产物、截图及临时数据。按调用链追踪录入、财务、数据导入导出、计划、分享、IPC、本地服务、备份恢复与发布脚本，再以隔离测试验证改动。

该范围覆盖全部模块，不表示穷尽每一条运行路径。没有清理用户数据库、收藏图片或本机配置，没有调用真实 AI 服务或执行线上发布。代码审核阶段未生成分发文件。后续已经用户明确确认，重新生成并验证安装包与便携包；产物状态见[发布说明](./release-v1.3.0.md)。

## 架构与模块职责

| 目录 / 模块 | 职责与审核重点 |
| --- | --- |
| app / components | 页面、Server Actions、API、表单状态、导航上下文、双语界面和共享控件。 |
| 财务领域 lib | 整数金额、实物数量、付款组成、人工汇率、移动平均成本及缺失值。 |
| 首页与组合 lib | 分页、报表索引失效、排序、历史趋势、质量与冻结快照。 |
| 数据与计划 lib | 映射预演、逐行事务与指纹撤销、导出字段、180 天提醒和预算。 |
| 分享 lib | 编辑协议、白名单、媒体派生、统一 HTML 渲染、导出检查。 |
| electron | sandbox、可信 IPC、本地会话、服务生命周期、操作锁和密钥。 |
| electron/storage | 数据快照、清单、健康检查、恢复暂存和孤立媒体副本。 |
| prisma / scripts | 模型与初始化约束、增量升级、隔离验证、锁文件、CI 和经确认后的分发。 |

整体仍适合 Next.js + Electron + SQLite 的本地架构，本轮不重写核心引擎。领域规则保持集中，旧汇总字段不再建立第二套报表。

## 已处理问题

| 问题 | 处理结果 |
| --- | --- |
| 清理扫描与媒体引用写入竞态 | 暂停本地服务并复核引用，在数据库锁保护下移入 .recovery；共享生命周期协调覆盖备份、恢复、清理和 AI 设置重启。 |
| 整页 DOM 翻译可能改写用户内容 | 显式界面翻译；字典样式的中文用户内容在切换和编辑后保持原文。 |
| 首页全量查询、组合硬上限 | 首页 24 张分页、版本化报表索引、全局排序；组合每 250 张读取。 |
| 日志路径和异常降级 | 使用用户日志目录，轮转与写入失败降级。 |
| 表单失败丢输入、HTTP 断言过度依赖旧文案 | 状态化提交与输入保留；行为和目的地址回归。 |
| CI 截图只采集、发布实现分叉 | 严格比较固定 Chromium 基线；候选工作流复用正式发布实现。 |
| Git 忽略规则遗漏设置数据页面 | 将 data 规则限定到根目录，修复 app/settings/data/page.tsx 未进入源码管理的问题；版本检查增加源码误忽略检查。 |
| 打包工具链依赖漏洞 | fast-uri 3.1.5 → 3.1.7，@xmldom/xmldom 0.8.13 → 0.8.15；仅更新两项兼容依赖，CI 改为完整依赖审计。 |
| 已取消功能留下新建接口 | 移除批量修改/估值创建和最近批次列表查询；旧批次仍可读取、执行和撤销，新预演仅支持导入。 |
| 导出无条件加载财务和媒体关联 | 独立 card-data-export，只在私密 XLSX 加载流水，CSV 不构建工作簿；无效格式明确拒绝。 |
| 多套文件哈希实现、大包整文件读入 | backup-manifest 与两个分发脚本共用分块 SHA-256 工具，保留原有校验值大小写协议。 |
| 备份清单表数量缺失仍通过 | 校验完整表集合和数量，补充缺失、错误与额外表记录回归。 |
| 旧函数、界面残留和文档冲突 | 移除旧首页估值统计、无调用编辑包装、失效选择器与旧菜单翻译；设置折叠组件按职责命名，独立数据页与设置内展开复用同一数据工作区。 |

## 有意保留的内容

- 旧导入批次、档案修改/估值批次及撤销证据，避免旧数据无法恢复；退役的通知字段不再驱动功能，但不做破坏性删列。
- 支持范围内的 v1.1.0、v1.1.1、v1.2.0 数据初始化和备份恢复分支。历史快照保留当时核算与汇率依据。
- 原字重恢复方案、已确认按钮位置及独立折叠，不借代码整理再次改版。
- 旧路径重定向、财务兼容字段、动态 CSS 状态类及共享渲染协议；不以静态搜索无字面匹配就盲目删除。
- 历史发布说明保留发布时事实，并注明归档性质；现行规范与路线图不再复制这些过程。

## 验证与边界

本轮源码发布门槛已通过，239 项单元与模块测试、65 项 UI 回归及全部 HTTP 流程通过；完整依赖审计为零已知漏洞。完整结果见[开发进度](./v1.3.0-implementation.md)。日志位于本机忽略目录 logs/v130-consolidation。数据写入、批次撤销和恢复测试均使用隔离数据库。

仍需后续验证的范围：新包实际安装/覆盖升级/便携运行、真实签名、受限 Windows 安装目录、大图片与密集流水的内存表现、磁盘耗尽和断电恢复、真实 AI 提供商与用户工作流程。当前没有手机应用；窄视口只验证分享网页。

大收藏财务仍需在内存构建投影，首次查询成本会随档案与历史增长；送评和在售时长从最近档案修改日近似。清理未引用媒体必须经桌面协调入口，不能将独立存储脚本并行用于仍在写入的用户目录。以上边界在当前版本保持明确，不视为本轮已交付在线或移动功能。
