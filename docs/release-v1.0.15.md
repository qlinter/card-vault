# Card Vault v1.0.15 更新说明

发布日期：2026-08-13。

## AI 组合分析升级

- 首页组合分析采用完整新版分析协议，直接消费扩展后的组合快照数据。
- 增加结构、财务、收藏质量、流动性、数据质量、集中度、覆盖度、趋势和重点关注项等分析维度。
- 统一 AI 响应 JSON 提取、版本校验、字段边界、证据和数据充分度规范化流程。
- 保留解析失败后的修复请求，并在前端报告中展示置信度、证据、数据充分度和后续行动建议。

## 工程结构整理

- 拆分 Electron 主进程、存储管理、IPC、备份恢复、窗口管理、日志和本地服务运行时。
- 统一应用与脚本的默认存储路径规则，避免数据目录和数据库路径解析不一致。
- 拆分分享编辑器向导状态、历史记录、草稿恢复、导航和四个设置面板。
- 拆分组合分析类型、范围、快照、统计和结果规范化模块，保留原有导入入口。
- 集中页面、Server Action 和 AI API 的成功提示映射与异常消息处理。

## 构建与依赖整理

- 移除未实际使用的 Tailwind CSS 配置、PostCSS 配置、全局指令和依赖。
- 保留现有自定义 CSS 和页面视觉表现，不改变现有 UI 样式契约。
- 增加反馈消息、存储路径和新版组合分析的自动化测试。

## 数据兼容与发布边界

- v1.0.15 不新增数据库迁移，不改变现有数据表结构和历史迁移 ID。
- 现有 v1.0.14 数据可直接升级使用；备份、恢复和存储路径迁移规则保持兼容。
- Windows 安装包和便携 ZIP 已生成，并通过打包运行时冒烟测试。
- 未配置签名证书时仍可生成未签名包，但 Windows 可能显示未知发布者或 SmartScreen 提示。
