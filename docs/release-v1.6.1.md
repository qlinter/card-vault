# v1.6.1 版本说明

源码版本更新于 2026-11-18，包含 v1.6.0 之后的全部改动。已发布的 Windows 分发版本见 [v1.6.1](https://github.com/qlinter/card-vault/releases/tag/v1.6.1)。

## 使用变化

- 收藏和录入统一采用「卡牌」。清空筛选会同时处理已应用条件和当前输入。新增页在上传区下方提供 AI 识图，默认使用前两张卡图，队列录入沿用队列图片。「另选识别图片」支持单独参考图，收起即切回默认来源。手写备注在选图、识图和恢复草稿后保留。
- 展示网格只显示有值的版本、评级和限量编号，列表保留固定列。展馆支持按当前范围「排除已售」，可将该选项保存为本机偏好。操作按钮和展馆标签使用统一样式。
- 分享集的底部操作栏显示保存进度和错误，缺少标题时聚焦输入框。统计明细在窄窗口横向滚动时固定卡牌名称列。
- 买入、评级、卖出费用均按卡牌登记。「平台费用」更名为「销售扣点」，「计入卖出成本」可以独立录入。历史数据继续按原有结构读取。计算方式见[统计与财务模型](./financial-history-model.md)。

## 源码整理与验证

收藏与统计共用筛选字段表，展示搜索、排序与展签列共用定义。展馆设置与本机偏好共用播放间隔校验。分享和财务表单共用文本读取方法，已清理录入页失效样式。CSV、XLSX、卡图和回顾长图共用流式下载响应，输出字节数可独立核验。

Next.js 已升级至 16.4.6。官方 npm registry 审计未报告生产依赖漏洞；包含开发依赖的审计仍标记 7 个高风险、10 个中等风险依赖节点，涉及 Electron 打包与 TypeScript 检查工具链。部分节点没有自动修复，部分修复建议跨主版本降级打包器，需独立评估。

完整源码检查 `npm run check:release` 通过。412 项模块测试全部通过，行覆盖率 94.40%；262 项桌面及窄屏界面测试全部通过。另有 12 组业务、账户、Electron 和代理检查通过。流式导出以 600 张合成卡牌、22,800 条财务流水核对了 CSV 和 XLSX 的下载字节数与行数，并验证取消及临时文件清理。验收记录见 `logs/v161-final-source-check.log`。

## Windows 分发

Windows x64 安装包和便携 ZIP 已通过结构、可执行文件版本、未签名状态及 SHA-256 验证。从 ZIP 重新解压后，全部 11 组包内运行检查通过，覆盖卡牌、分享、数据管理、寻卡、流式导出、账户、健康端点和桌面交互。下载时可核对 `SHA256SUMS.txt`；构建和独立验收记录分别见 `release-1.6.1.json` 与 `verification-1.6.1.json`。
