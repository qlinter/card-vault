# Card Vault v1.0.14 更新说明

发布日期：待确认打包后填写。

## 分享编辑器与导出

- 完成分享展馆编辑器 2.0：四个工作区、拖拽和键盘排序、最多 80 步撤销/重做、本机草稿恢复、封面和背景即时预览。
- 增加字体风格、内容密度和图片构图设置，并保持旧分享集兼容。
- 修复应用内预览点击单卡后加载完整 Card Vault 界面的问题。
- 合并分享包导出入口；通用静态包与 Cloudflare Drop 包共用同一网页渲染器。
- Drop 包增加 noindex、安全响应头、404 页面、发布清单、一小时临时发布说明和完整性检查。
- 导出继续采用公开字段白名单，不包含财务数据、购买渠道、私人备注、AI Key 或本地路径。

## 财务历史与首页估值

- 增加购买、售出、退款、费用和估值历史，金额使用整数最小货币单位保存。
- 卡片详情页支持新增、按币种汇总、统一时间线、纠错和删除；普通卡片编辑不再覆盖财务历史。
- 币种仅支持 CNY/USD；估值来源仅支持个人估计、近期成交和平台报价。
- 旧财务字段自动迁移为可追溯基线；所有旧估值来源统一为个人估计，非 CNY/USD 历史记录在迁移中删除。
- 首页总估值针对当前筛选出的全部卡片，每张只采用业务日期最新的一条估值，不按收藏状态排除，也不重复累计历史估值。
- CNY/USD 固定分行显示，统一使用 ISO 代码、千位分隔符和相同字号；覆盖度简写为“估值覆盖 x/y”。
- 首页组合分析直接使用交易、费用和估值历史，按 CNY/USD 分别呈现成本基础、净现金占用、可比未实现盈亏、估值时效和估值来源，不跨币种合计或假设汇率。
- 有售出记录但仍处于活跃状态的复杂仓位不计算可比收益率；现有数据无法可靠配对出售数量与成本批次，因此不虚构已实现收益。

## 数据恢复与可靠性

- 从旧备份恢复时，先在暂存目录执行全部待办迁移和完整性检查，成功后才替换当前数据。
- 恢复前继续生成当前数据安全备份；迁移或校验失败时不替换当前数据。
- 桌面启动脚本会检查依赖缺失及锁文件新旧状态，并在需要时自动安装依赖。
- 首页、组合分析、卡片财务摘要和兼容快照统一使用同一套“业务日期优先、创建时间解决同日并列”的最新估值判定规则。
- 精简重复的 Windows 发布命令入口，并将数据备份说明迁入 `docs`、更新为 v1.0.14 的恢复与历史迁移流程。
- 新增财务历史、恢复自动迁移、币种约束和最新估值计算的自动化测试。

## Windows 发布签名

- v1.0.14 支持可选 Authenticode 签名；未配置证书时仍可直接生成安装包和便携包，不再执行强制证书验证。
- 配置 PFX、证书存储/EV 或 Microsoft Artifact Signing 后，主程序和 NSIS 安装器会自动使用同一发布身份签名；PFX/证书存储方式使用 SHA-256 与 RFC 3161 时间戳。
- 证书路径、密码和 Microsoft Entra 凭据只通过当前 PowerShell 会话或 CI Secret 注入，不写入源码、`.env`、数据库或发布包。
- 未签名包可能触发 Windows“未知发布者”或 SmartScreen 提示；普通 OV 新证书也可能经历信誉积累期。
