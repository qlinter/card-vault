# Card Vault v1.2.1 更新说明

发布日期：2026-08-28。

v1.2.1 统一归档 v1.2.0 之后的界面国际化、Windows 发布流程、分享展馆升级、预览修复和工程收敛。本版本不修改 Prisma 模型或 SQLite 结构，数据库基线继续使用 v1.2.0。

## 中英文界面

- 新增中文与英文实时切换，选择结果保存在本机。
- 英文模式覆盖首页、录入、组合、设置、展示、分享、详情、编辑和导出等主要页面。
- 中文界面删除组合中心重复的中英文标题；英文界面只保留对应英文名称。
- 补齐动态“显示更多”、数据质量、已售复盘、AI 设置和关于页面的英文文案。
- 建立桌面和手机双视口的英文残留自动检查。

## 分享展馆

- 将“展馆模板”和“展馆版式”合并为“展馆样式”，主题保持独立。
- 保留“选择球星卡、AI 生成、内容修改、确认保存”四步，并删除重复说明文案。
- 提供藏家聚光、典藏志和主场阵容三种样式，以及独立主题、背景、封面、字体、密度、图片构图和文字面板不透明度设置。
- 修复主题不统一响应文字面板不透明度的问题，将有效范围收敛为 10%–90%。
- 增加桌面 1440px、平板 768px、手机 390px 实时预览和共享响应式设计变量。
- 修复独立预览页退回浏览器默认小 iframe 的问题；现使用接近完整窗口的居中画布，最大宽度 1600px，高度至少 640px。
- 增加最多 6 张重点卡、单卡故事、章节页、卡片主体页和单卡页。
- 导出生成有界 WebP 展示图与缩略图；大型展馆采用 24 张首屏精选和每批 48 张的完整馆藏浏览。
- 导出前检查断链、公开字段、页面结构和无障碍；每次导出生成 `EXPORT-DIFF.md`。
- 背景图、封面图和临时发布流程继续保留；二维码不属于当前产品目标。

## Windows 发布与可选签名

- `release:win` 在没有证书时允许生成经过完整门禁的未签名安装包、便携 ZIP 和 SHA-256 清单。
- 未签名模式验证安装器与便携主程序均为 `NotSigned`，并明确提示 Windows 可能显示“未知发布者”或 SmartScreen。
- 配置 PFX、Windows 证书存储/EV 证书或 Microsoft Artifact Signing 后自动切换为签名模式。
- 签名模式统一使用 SHA-256 和 RFC 3161 时间戳，并验证安装器、主程序、签名者和时间戳。
- GitHub Actions 同时支持无证书发布和可选签名，任何模式都必须通过完整测试、版本、运行时、结构与校验和检查。

## 工程与文档收敛

- 删除已退出界面的翻译键、辅助文案和无调用方样式，合并重复的预览容器规则。
- 分享编辑器 2.0 与分享展馆 3.0 的阶段文档合并为唯一现行《分享展馆规范》。
- 新增统一文档索引，明确 README、现行规范、路线图和历史发布说明的职责。
- 中英文路线图同步把分享展馆标记为已完成，并收敛批次历史描述。
- 增加 Markdown 本地链接与文档分叉检查，防止重新引用已移除的历史规格。
- 应用“关于”页面更新为 v1.2.1 的真实变更和日期。

## 数据与兼容

- 产品版本升级为 `1.2.1`，数据库结构版本仍为 `1.2.0`。
- 不新增数据库表、字段或迁移，不重写卡片、财务历史、收藏视图、快照或媒体文件。
- 分享展示协议保持 JSON 向后兼容；旧分享集缺少新字段时使用兼容默认值。
- v1.1.0、v1.1.1 备份继续沿用既有受控升级与恢复路径。

## 验证状态

- UTF-8、版本元数据、文档链接、ESLint 和 TypeScript 检查通过。
- 204 项单元与集成测试通过，整体行覆盖率保持在 93% 以上。
- 本地会话安全、卡片 HTTP 流程、分享 HTTP 流程和生产构建通过。
- 56 项桌面/手机 UI 测试通过，包含中英文审计、分享编辑器和独立预览视觉基线。
