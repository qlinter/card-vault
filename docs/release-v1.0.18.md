# Card Vault v1.0.18 更新说明

发布日期：2026-08-17。

## 首页与组合分析性能

- 首页卡片图片改为延迟加载和异步解码，减少首屏之外图片同时解码造成的主线程压力。
- 卡片列表使用浏览器的不可见内容跳过机制，并移除每张卡片上的背景模糊，提升大量卡片上下滚动时的响应速度。
- 组合分析遮罩取消高成本背景模糊，加载动画仅提示浏览器优化必要的变换属性。
- 打开组合分析时锁定底层页面滚动，弹窗与遮罩限制滚动链，避免等待 AI 结果时页面争抢滚动和重绘。
- 分析弹窗在请求期间提供 `aria-busy` 状态，不改变现有五维报告、确定性计算或本地保底逻辑。

## Electron 渲染兼容

- Electron 默认恢复硬件加速，改善桌面端列表滚动和弹窗动画性能。
- 显卡驱动或远程桌面环境不兼容时，可设置 `CARD_VAULT_DISABLE_GPU=1`，或使用 `--disable-gpu` / `--software-rendering` 启动参数进入软件兼容模式。
- 桌面日志会记录本次启动采用硬件加速还是软件兼容模式，便于定位特定设备问题。

## 跨电脑启动与依赖恢复

- `start-desktop.bat` 同时检查 Node.js、npm、依赖树、Electron 可执行文件和依赖指纹，避免仅凭文件时间判断依赖是否过期。
- 依赖指纹覆盖运行平台、Node.js 主版本、依赖声明、安装脚本和锁文件中的实际包元数据；仅修改应用版本号不会触发无意义的依赖重装。
- 缺失或过期时使用锁文件重建依赖，并关闭非必要的 audit 与 fund 网络请求。
- npm 缓存和安装日志保存在项目 `.npm-cache` 中，减少不同 Windows 用户缓存权限差异造成的启动失败。
- npm registry 使用 npmmirror 时自动匹配 Electron 下载镜像，同时保留用户显式设置的 `ELECTRON_MIRROR`。
- 启动提示明确 `npm warn deprecated` 为非致命警告，并在真实安装失败时显示项目内日志位置。

## 设置与版本信息

- 设置页新增可折叠的“关于”区域，标题栏仅显示“关于”和当前应用版本。
- 展开后保留更新说明、项目主页和版权信息，视觉样式与其他设置板块一致。
- 版本号直接读取项目发布元数据，避免开发环境误显示 Electron 运行时版本。

## 代码收口与质量

- 将启动批处理内两份重复的依赖指纹实现合并为独立工具，并增加自动化测试。
- 合并组合分析弹窗重复的打开状态副作用，在同一生命周期内管理 Escape 关闭和页面滚动锁定。
- 保留首页渲染、分析弹窗和 GPU 兼容模块的独立边界；未发现可安全删除的数据库迁移、备份恢复或发布兼容路径。
- 自动化测试共 102 项，继续覆盖 AI、财务历史、组合分析、分享、存储恢复、发布、渲染模式和依赖指纹。
- v1.0.18 不新增数据库表或迁移，v1.0.17 数据和备份可直接继续使用。
- 安装新版不会主动删除收藏数据；升级前仍建议通过设置页执行一次完整备份。
