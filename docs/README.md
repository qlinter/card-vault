## 文档维护规范

- README 只保留产品概览、当前版本、安装运行和权威文档入口。
- 功能规范描述当前行为，不继续按开发批次堆叠历史过程。
- 路线图区分“已完成、后续阶段、远期方向”，已完成项必须写明最终发布版本。
- 版本说明只记录该版本相对上一正式版本的变化、兼容边界、验证结果和产物状态。
- 数据库结构版本与产品版本分开记录；没有数据库变更时不得为了产品升级改写数据库基线。
- 中英文路线图保持相同阶段状态与范围。
