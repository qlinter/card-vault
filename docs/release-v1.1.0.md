# Card Vault v1.1.0 更新说明

发布日期：2026-08-21。

## 录入工作台 2.0

- 新增 SQLite 录入草稿、自动保存与中断恢复；草稿只保存表单字段，不复制临时选择的本地图片。
- 保存卡片时可选择查看详情、继续录入或复制公共字段新增；复制模式不携带编号、证书、图片和财务数据。
- 新增公共字段录入模板，可创建、应用、更新和删除，并记录最近使用顺序。
- 新增疑似重复卡提示，根据球员及年份、产品线、卡号、平行版本、证书号等匹配依据给出候选，但不阻止保存。
- 从重复候选进入详情前会保存草稿；“返回上一页”会恢复真实浏览历史，并保留草稿及批量队列上下文。
- 增加保存、继续录入和队列前后切换快捷键，并在校验失败时定位首个必填项。

## 批量图片与 AI 候选

- 新增可折叠的批量录入队列，可按选择顺序组成正反面项目，也可将每张图片作为独立项目。
- 队列图片读取 EXIF 方向，将最长边限制为 2400 像素并转换为 WebP；普通单卡上传仍保留原始图片格式。
- 单项预处理失败不会影响同批其他项目，可独立重试、移除或交换正反面。
- 保存卡片时以事务方式接管队列 WebP，成功后进入下一待录入项目；提交失败时不丢失队列图片。
- AI 批量识别只在用户主动启动后运行，结果作为持久化候选写入工作台，显示低置信字段并要求逐卡确认。

## 数据迁移与备份

- 新增 `010_card_entry_drafts_v1_1_0`、`011_card_entry_image_queue_v1_1_0` 和 `012_card_entry_workbench_phase3_v1_1_0` 三项可重复执行的迁移。
- 迁移前继续创建 SQLite schema 快照；应用启动和旧备份恢复都会自动执行尚未完成的迁移。
- `entry-queue` 源图、队列 WebP 和数据库记录已纳入备份、恢复、路径迁移、健康检查与孤儿文件清理边界。
- 升级不会批量转换历史卡片图片；只有批量录入队列的新图片会预处理为 WebP。

## 代码与质量收口

- 卡片写入、媒体保存、队列处理、识别候选、重复判断和模板规则均集中在领域层与服务层。
- 合并模板与 AI 面板重复的表单控件逻辑，统一录入 API 的 ID 校验和错误响应，并复用单一 AI 字段定义。
- 分享动作与静态导出共用 slug 规则，分享导出校验与 ZIP 打包共用目录遍历工具，存储健康检查复用媒体文件枚举逻辑。
- 卡片与分享 HTTP 流程共用服务启动、健康检查和临时目录清理工具，移除 Windows 清理阶段的同步忙等待。
- 统一当前版本入口文档、备份说明、签名说明和发布文件名，并保留历史版本说明作为升级记录。
- 发布检查覆盖编码、元数据、Lint、TypeScript、覆盖率、数据库迁移、安全流程、卡片与分享 HTTP 流程、生产构建及生产依赖审计。

## 分享与桌面稳定性

- 恢复内置主题背景在应用预览沙箱中的同源素材加载，继续禁止表单提交和顶层导航。
- 多图轮播按钮改用居中的 SVG 箭头，避免字体字形造成视觉偏移。
- 移除桌面启动前重复生成 Prisma 客户端的步骤，避免 Windows 占用查询引擎文件时触发 `EPERM`；依赖安装和生产构建仍会生成客户端。

## 界面精简与一致性

- 精简录入工作台、展示、分享和设置页的辅助说明，保留操作本身及必要状态反馈。
- “录入模板”缩短为“模板”，批量录入数量改为纯数字显示。
- 展示页和设置页的展开操作统一使用居中的 SVG 箭头，同时保留可访问名称和展开状态。
- 批量录入数量徽标与展开箭头使用同高对齐盒；设置页“存储数据、备份与恢复、AI 设置、关于”统一字号、字重和行高。

## 数据兼容提醒

- 安装新版不会主动删除收藏数据；升级前仍建议在设置页执行一次完整备份。
- 未完成的草稿、模板与批量队列属于本地收藏数据，会随完整备份迁移。
- AI Key 继续保存在当前 Windows 用户配置目录并由 Electron `safeStorage` 加密，不进入收藏备份或发布包。
