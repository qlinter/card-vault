# Card Vault v1.0.16 更新说明

发布日期：待发布。

## 阶段性稳定版本

- 将 v1.0.16 定位为稳定性与可重复发布版本，不新增数据库表或迁移，不改变 v1.0.15 的业务数据口径。
- 首页只读取列表展示所需字段和每张卡片最新一条估值，不再随首屏加载完整交易、费用及估值历史。
- 组合分析改为点击后由服务端按照当前筛选条件重新查询并生成快照，保持现有 CNY/USD、估值来源、成本及覆盖度计算方式。
- 对组合分析筛选输入增加字段白名单、类型和长度限制，并限制单次分析的最大卡片数量。

## 可重复构建与发布

- 明确使用 Node.js 24 和 npm 11.9.0，并让源码桌面启动在依赖缺失或锁文件变化时执行 `npm ci`，清除跨电脑同步后遗留的多余依赖。
- 增加 GitHub Actions Windows 质量工作流，在全新环境执行依赖安装、编码检查、元数据检查、类型检查、自动化测试、生产构建及 HTTP 端到端测试。
- 增加可手动触发的 Windows 发布候选工作流，生成安装包、便携 ZIP 和 `SHA256SUMS.txt`，但不会自动创建 GitHub Release。
- 发布流程增加打包后 Next.js `/api/health` 运行时冒烟测试，并提供独立的发布文件版本、ZIP 结构和 SHA-256 验证命令。
- 增加版本、锁文件、README、发布说明和产物文件名的一致性检查。

## 回归与质量加固

- 增加首页轻量查询与组合分析完整查询的边界测试，防止以后重新把完整财务历史带回首屏。
- 修复组合分析测试数据中的历史乱码文本，并扩大 UTF-8 乱码模式检查。
- 自动化测试增加到 87 项；包含 1,000 张卡片组合快照及 v1.0.15 兼容备份恢复回归，完整发布检查继续覆盖卡片新增/编辑/详情和分享集新建/编辑/预览/导出流程。
- 使用 npm 官方安全数据库审计生产依赖，当前未发现已知漏洞。

## 数据兼容

- v1.0.16 不新增数据库迁移，v1.0.15 数据可直接升级使用。
- 旧版本备份仍会在暂存目录完成待办迁移和 SQLite 完整性检查后再替换当前数据。
- 安装新版程序不会主动删除当前数据；升级前仍建议通过设置页执行一次完整备份。
