# Card Vault v1.3.5

更新日期：2026-10-04。本版本统一收录今天的稳定基线、界面精简、主题升级、AI 设置调整及本轮全项目审查。源码与 Windows x64 分发版本均为 `1.3.5`；经用户确认，安装包、便携包与 SHA-256 清单已生成并通过本次独立验收。

## 本版本更新

- **应用主题**：设置新增经典、极简展厅、午夜典藏、暖纸档案，保留现有字体与字样设计。选择即时生效并持续记忆；服务端首屏读取同一选择。经典各页面统一使用首页背景图。主题区仅保留预览、名称和选中状态，移除默认标记、介绍、当前主题及恢复按钮。分享集主题与导出保持独立。
- **财务与编辑**：详情页“财务历史”统一为“财务”；删除详情工具栏、编辑页的重复财务按钮，去掉编辑页财务分离提示及顶部标题说明。交易、费用和估值在详情页直接编辑，资料保存不改写财务流水。
- **视图切换**：首页、展示和数据导出统一使用网格、列表、表格图标；保留可访问名称、选中状态、键盘操作及视图记忆。
- **AI 设置**：内置服务与自定义服务的字段名称统一为 Endpoint、API Key。新增自定义 AI 入口归入当前服务选择区，模型参数单独显示；移除自定义配置标题、兼容服务说明及新增成功提示，直接进入配置表单。
- **稳定基线**：更新 Next.js 16.3.8、Electron 41.10.7、TypeScript ESLint 8.71.0 及相关依赖补丁；锁文件保留精确的 `brace-expansion` 5.0.12 覆盖。未增加外部服务、自动发布或新的数据库升级路径。

## 审查与结构清理

- 删除旧目标卡的状态标签、编辑、导入、数量回退、购入转换和模板应用分支，以及对应兼容测试、翻译与说明。现行收藏状态只有持有、待送评、送评中、待售、已售；购买计划使用心愿单。
- 删除 `/uploads/` 到 `/media/` 的旧图片地址转换及 `image-path` 包装模块，页面和分享预览直接使用当前媒体地址。健康检查拒绝无效媒体路径；检查失败时禁止清理，保留文件。
- 删除旧组合快照按档案数替代估值覆盖分母的回退，移除 `portfolio-coverage` 包装模块。覆盖分母是当前格式必填字段；已保存快照必须包含当前财务口径，缺失或不支持的快照需重新保存，不转换旧内容。
- 删除卡片表旧人民币摘要的六个模型和建表字段、摘要同步模块及兼容测试；金额、日期和来源直接读取财务流水，排序统一读取当前报表，删除 v1.0.18 的 `priceAsc` / `priceDesc` 参数别名。新库不再重复存储摘要，既有数据库不执行删列；录入快捷字段与持仓数量同步保持有效。
- 主题名称、背景与颜色集中在主题注册表，界面与服务端共用；扩展流程见[应用主题](./app-themes.md)。本版双语更新要点与日期集中在 `lib/release-notes.ts`，关于页只负责呈现。
- 删除不再使用的设置页背景图；仅作测试卡图的原展示、分享背景移入测试素材目录，保留同一截图数据，避免继续随应用分发，公开资源减少约 316 KiB。
- 删除已退役系统摘要通知的 Prisma 字段、建表字段及设置写入；新库的管理设置只保存摘要周期，既有数据库不执行删列。数据目录检查统一命名为 `ensureDataLayout`，移除“修复旧布局”的误导命名与无作用包装，不增加别名兼容层。
- 现行文档描述当前规则；2026-10-04 的分散开发记录合并到本页，v1.3.4 发布说明恢复为历史记录。同步双语 README、路线图、文档索引、使用说明、主题、财务、备份及分发规范。

数据库结构标记仍为 `1.3.0`，核算版本为 `physical-position-v2`，AI 加密配置为 v5，分享展示协议为 v3，备份清单为 v1。当前格式创建、只读校验、数据目录迁移、备份恢复与回滚继续使用现行实现；没有操作真实收藏数据、清除备份或改写历史分发文件。
