# v1.5.3 版本说明

日期：2026-11-12。基于 v1.5.2，提供 Windows x64 安装包与便携包。

## 录入反馈

- 新增卡片缺少图片时在提交前提示，队列已有图片时可直接保存；草稿图片仍需完成恢复后提交。
- 缺图、必填项和输入格式问题集中显示在保存按钮上方，自动滚动并聚焦提示；可点击“定位问题”返回对应字段。
- 仅空格的必填内容同样拒绝提交。服务端校验与提交前草稿同步失败使用同一反馈区域，保留已输入资料与选中图片，允许修正重试。
- 服务端现有校验、提交身份、重复请求保护和数据库格式保持不变。

## AI 识图入口

- 新增页的 AI 面板默认展开，采用公共标题字号、浅色分区和轻量按钮；去除彩色边线、渐变及双层外框。编辑页保留原有折叠入口。
- 录入面板去除说明性文字，图片用途说明集中在使用说明中；识别图片不自动转存或覆盖用户图片。
- 识别失败使用错误提示及无障碍告警；识别成功、取消及一般状态保留普通反馈。测试仅使用模拟 AI 响应。

## 界面细节

- 收藏页的搜索、清空条件、新增卡片及目标与寻卡使用公共轻量操作样式，去除明显外框和按钮阴影。
- 文件选择框统一为 40px，内层按钮为 30px，上下留白一致；录入、编辑、批量导入、数据导入和分享图片上传共用同一规则。

## 代码、界面与文档整理

- 录入控件类型判断、错误关联及定位复用 `card-form-display.ts`；修正校验清理时覆盖字段原有辅助说明的问题。
- 草稿删除补齐网络异常、非 JSON 错误和重复点击处理；失败保留草稿并允许重试。草稿时间按界面语言显示，删除不可达的空列表分支。
- 清除已停用财务页签样式和无用途的按钮类名；轻量按钮补齐禁用态，AI 标题与设置操作垂直居中，保留已确认的页面设计。
- 统计指南并入统计与财务模型，Windows 分发指南并入开发维护；维护文档总数由 16 份减为 14 份。迁移章节锚点与现有引用，历史记录只更新链接位置。

全站 248 项界面回归通过，包含中英文、四种主题、录入反馈、并发编辑保护、统计、回顾、展馆、分享、设置及移动端分享预览。最终帮助文字整理后重新构建，并通过 7 项录入反馈与帮助页定向复核。草稿删除检查覆盖网络断开、非 JSON 服务错误及成功重试；校验提示检查保留字段原有辅助说明。文件控件在 8 个实际入口测得上下各 5px。截图比较阈值保持不变。

文档检查覆盖 14 份 Markdown、章节锚点及 37 个双语历史版本。当前版本说明、应用内说明及文档索引已同步，修正使用说明中 AI 栏展开方式的过时表述。验证日志位于 `logs/v1.5.3-review-*`；详细控件测量见 `logs/quiet-controls/measurements.json`。

本轮按要求未运行模块测试。界面检查使用隔离数据库及模拟 AI，未操作个人收藏或连接外部模型。

## 发布后的源码修正

首次 GitHub Quality 检查（run `43196530641`）的 248 项界面用例中，247 项通过，草稿删除用例捕获 React #418 首屏文字不一致。删除、失败提示和重试本身正常，原因是草稿时间在 UTC 服务端与上海时区浏览器中格式化结果不同。

后续源码将草稿时间首屏统一为 ISO 时间，客户端接管后再按界面语言与用户本地时区显示；使用语义化 `time` 元素保留原始时间，不屏蔽渲染错误。UTC 服务端下的上海／洛杉矶、中英文时间显示及录入反馈共 9 项界面检查通过，生产构建和定向 ESLint 通过；本地未运行模块测试。

修复提交 `545f982` 的 [GitHub Quality 检查](https://github.com/qlinter/card-vault/actions/runs/43200999635)已通过，包含 252 项界面回归。修订分发以该修复代码重新构建两份产物，再从便携 ZIP 解压检查实际包内时间渲染。初版产物及校验文件保存在本机 `logs/v1.5.3-initial-distributions/`；新旧产物来源和校验值在修订构建清单中分别记录。此次更新需要重新下载安装包或便携包，旧文件不会自行获得修复。
