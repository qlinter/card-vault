# v1.7.0 版本说明

2026-11-23 · Windows x64 正式版

- 本地账户可启用访客浏览。访客仅可浏览公开卡牌及其展馆图片。
- 单卡财务图以时间走势比较剩余成本与估值，支持查看各记录日和售出归零。
- 新卡保存后，使用本机 OpenAI 配置按首图生成展馆 PNG，识别横竖方向并匹配卡砖、评级壳或大尺寸卡的陈列方式。
- 展示的展墙、详情、大图与浏览默认优先显示 AI 展馆图，可切换到录入原图。未生成展馆图时使用录入图片。
- 新增或编辑卡牌时，预览中以「✓ 首图」标出用于生成展馆图的照片。点击其他照片的「设为首图」可保留原首图并切换；要用评级后的照片替换旧照片，将新照片设为首图，并在旧照片下勾选「删除此图」。删除首图后会使用下一张，旋转首图也会更新展馆图。
- 缺少 Key 或生成失败时，卡牌正常保存。配置 OpenAI 后可在「设置 → AI → AI 展馆图」补生成缺失图片。
- Windows 恢复备份时支持收藏根目录被占用的情况。展馆图的保存、补生成与恢复规则见[数据与本机配置](./data-guide.md#backup)。
