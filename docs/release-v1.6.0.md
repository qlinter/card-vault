# v1.6.0 版本说明

日期：2026-11-16。基于 v1.5.3，新增离线本地账户及应用访问保护。源码整理已获用户确认，Windows x64 安装包和便携包已生成并通过分发验证。

## 本版变化

- 每份本机应用配置使用一个账户。首次创建用户名和密码、确认保存恢复码后直接进入现有收藏，无需迁移数据库。密码为 8–128 个 Unicode 字符，格式不符时提交弹出提示；密码显隐统一为眼睛图标。
- 登录保护页面、媒体、接口、服务端表单和桌面操作；完整退出应用及 Windows 锁屏后需重新登录，刷新页面和内部服务重启保留有效会话。
- 设置采用紧凑的连续列表，统一宽度、分隔和内边距。账户与安全默认收起；底部左侧为帮助与版本，右侧为纯文字退出按钮，帮助展开时按钮位置保持稳定。顶栏只保留设置与语言工具。
- 账户与安全支持修改用户名、密码及更换恢复码。错误提示按登录、当前密码和恢复码区分；恢复码只提供显示与保存确认。更换恢复码期间仅显示确认界面，确认后重新登录。

## 全面整理

- 核对收藏、录入、卡片详情、展示、展馆、分享、统计、回顾、寻卡和设置的中英文字体、字号、按钮、表单及窄屏排版；统一账户表单标签字重，保留作品展示自身的排版层级。
- 清理 62 条没有运行时引用的旧样式选择器，涵盖旧帮助面板、批量卡片选项、导出分页、旧心愿与分享流程；合并相同导出按钮规则，不清理个人收藏或已有数据库表。
- 账户状态读取、退出遮罩和返回登录集中维护。修复更换恢复码时定时校验或窗口切回可能提前退出确认页的问题；待确认令牌不授予收藏或桌面权限，确认完成后撤销会话。浏览器消息广播不可用时仍可完成退出。
- 主文档由 14 份合并为 12 份：分享规范并入收藏展示指南，代理说明并入数据与本机配置指南；历史引用同步更新，38 个双语历史版本完整保留。本页集中记录当前结论，逐轮日志不再重复写入文档。

## Windows 分发验证

在已通过源码验收的基础上，以 `release:win:package` 重新构建两个分发文件；从便携 ZIP 重新解压后，另行通过 11 组包内检查：卡片、分享、数据管理、寻卡、流式导出、账户 HTTP 保护、健康端点、桌面启动与编辑返回、AI 配置、收藏回顾与赏卡、桌面账户与锁屏。版本、结构、签名状态及 SHA-256 均已核验；包内账户代码与本次源码一致。

生产依赖审计无已知漏洞；开发工具链有 12 项中等风险提示，无高危或严重项。此次沿用已验收的依赖锁文件。

构建清单 `release-1.6.0.json` 保留仅打包模式的自动跳过标记；补充清单 `verification-1.6.0.json` 记录复用的源码验收、独立完成的包内检查、产物哈希和发布源码提交。详细本机记录为 `logs/v1.6.0-package.log`、`logs/v1.6.0-packaged-runtime.log` 及 `logs/v1.6.0-packaged-validation.json`。

## 数据与交付边界

账户配置与收藏数据库分离，不随收藏备份、CSV/XLSX 或分享导出迁移；恢复收藏不覆盖登录凭据。此功能保护应用入口，不加密数据库、媒体或导出文件。详见[数据与本机配置](./data-guide.md#account-security)和[开发维护](./development.md#account-security)。

发布文件为 `card-vault-1.6.0-setup.exe`、`card-vault-1.6.0-portable.zip`、`SHA256SUMS.txt` 及上述两份 JSON 清单，下载入口为 [GitHub v1.6.0 Release](https://github.com/qlinter/card-vault/releases/tag/v1.6.0)。本版未签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。
