# Card Vault v1.4.1

版本日期：2026-10-23。以 v1.4.0 为基线，本版升级数据工作区，优化首页、寻卡查询与桌面启动，并收拢相关代码和文档。

2026-10-23 的 GitHub 发布交付源码、Git 标签及版本说明；本地后续补充生成了安装包和便携包，范围见文末记录。已有 v1.4.0 分发文件和校验值仍属于[历史版本](./release-v1.4.0.md)。

## 数据工作区

- 导航“组合”改为“数据”，首页入口为“查看组合数据”；采用总览、趋势、结构、明细四页签，共享当前收藏范围。
- 顶部“调整范围”只提供关键词搜索，保留继承的其他筛选条件；条件可逐项移除。明细、结构下钻和编辑返回使用精确档案 ID 并保留上下文。
- 总览突出持仓估值、剩余成本、未实现和已实现盈亏；财务明细与核算依据按需展开，辅助说明字号统一。未估值及缺失成本、汇率不按零处理。
- 明细分为“持仓／出售／待完善／全部”，支持搜索、排序、问题分类及每页20项的完整分页。
- 财务趋势、活动趋势分别选择6／12／24个月或所有记录，期限随地址保留。“所有”从首笔相关记录所在月份开始；活动金额包含买入、出售和费用，数量只统计买入与出售的实物张数。
- 结构分布与卡片属性并排切换；档案数量含已售，实物数量和估值仅统计持仓，估值占比以当前范围已估值持仓为分母。已售且不再持有的档案单独标记并可下钻；Top 1／3／5同排展示，列表末尾提供展开或收起入口。
- 只保留固定快照，支持查看、重命名、删除和历史比较。比较选择器对象在前、基准在后，差额为对象减基准；重命名不改写冻结结果，核算版本或报表币种不同不能直接比较。旧动态视图表仅随原数据库与备份保留，不参与当前界面或查询。

规则统一见[数据分析板块](./data-analysis-guide.md)与[财务模型](./financial-history-model.md)。

## 首页、寻卡与启动

首页估值、卡片、收藏概览三栏紧凑对齐，估值金额和卡片总数使用相同字号；收藏概览静默保存统计周期，整理清单按需展开，收起重置已处理开关。列表图片与卡片信息合并为整行链接。视图切换控件压缩为图标；高级筛选保留全部条件，以小箭头展开，不再显示标题及横线，桌面主筛选项同排显示。

寻卡搜索使用250毫秒防抖、SQL分页、关联索引复用及异常缓存校验，保留关键词和心愿的既有功能。卡片详情移除“查找”入口。导航保留已有页面，较慢请求才显示进度，数据内容和比较分别支持失败重试。

`start-desktop.bat` 独立准备 Electron 运行程序并支持下载失败后重试，修复已有依赖却无法启动的情况。源码依赖升级至 Next.js 16.4.1、Electron 42.11.9，Node.js运行版本仍为24。

## 结构整理与边界

- 按职责拆分数据页、明细、结构、趋势、快照及上下文处理，删除旧组合长页面、拖拽布局模块和对应失效测试。
- 页面读取与快照动作共用同一状态参数白名单，趋势期限使用共享定义；损坏的快照上下文在写入前拒绝并返回页面提示。
- 寻卡读取共用精确金额和日期序列化；结构分组以自有字段保存计数，`__proto__`、`constructor`等名称不会读取内置属性或造成数量异常。
- 明细页保留轻量列表用于搜索与分页；其他页签在同一财务遍历中只保留汇总和前五项持仓，避免保留并排序整套明细。
- 清理旧页面遗留的16个无效样式选择器，保留比较盈亏动态样式；Windows发布只保留一个可手动运行及复用的工作流入口。
- 保留独立财务参考实现。产品版本升为1.4.1，数据库结构标记仍为1.3.0，核算版本仍为`physical-position-v2`，不重写用户交易和汇率。

交易与估值使用各自业务日期当天及之前最近生效的人工汇率；不会引用未来汇率。关键词不包含商品、价格或研究记录，本版没有自动抓取、自动更新或到价提示。
