# Card Vault v1.3.6

更新日期：2026-10-10。源码版本为 `1.3.6`，收录本轮规模优化、恢复加固、编辑导航、财务录入与来源调整，以及全项目结构整理。Windows x64 安装包与便携包已生成并通过独立验包，校验值见下表。

## 本版本更新

- **大收藏量**：组合每批读取 250 张卡片，完成计算后释放原始历史，仅保留汇总、月度曲线、质量清单及排行候选；同次计算复用卡片财务事实。10,000 张卡片、360,000 条估值交错对照各四次，峰值堆内存中位数由 270.5 MiB 降至 129 MiB，下降约 52%；耗时 7,599.5 ms 与 7,512 ms，基本持平。结果与原实现逐项一致，不将内存改善解释为整页提速。
- **恢复可靠性**：切换数据目录前持久化操作记录。原目录移动后、新目录切换后及最终校验后模拟进程退出，再启动均恢复正确目录；验证前的失败保留原数据，验证成功后的中断保留恢复数据。非法记录路径被拒绝，写入磁盘不足即时回滚。
- **编辑返回**：返回上一页跳过卡片与分享的编辑状态，也跳过编辑前后的同一详情页。筛选 → 详情 → 编辑 → 保存或取消 → 返回，会回到原筛选结果；刷新、连续取消、浏览器存储不可用时仍保留有效返回路径。
- **交易录入**：每笔交易填写一种币种，移除另一币种付款/收款和“金额尚不完整”选项。新增与编辑金额按完整金额保存，0 表示零金额。旧草稿勾选值忽略；历史未知金额和历史附加付款保留事实，金额更正后转为已知；初始购买价格留空仍保留未知成本，缺失值不自动变成零。
- **估值来源**：四个平级选项为“个人估值、卡淘成交、eBay成交、Others”，详情记录与组合分布使用相同显示。数据库保持 `个人估计/卡淘/eBay/Others`，历史“近期成交”转为“卡淘”，“平台报价”归入“Others”；草稿、模板、导入批次和冻结快照中的分类同步调整。恢复时先校验原清单，仅转换暂存副本并重建清单，原备份保留。

## 全项目审查与结构整理

审查覆盖路由、客户端组件、领域模型、桌面存储与 IPC、脚本、回归测试及全部 Markdown 文档；以源文件清单、导入图、重复函数检查、全文引用和完整发布门槛核对。

- 录入补充记录与详情新增/编辑共用 `FinancialRecordFields`，交易、费用、估值通过同一字段定义渲染；表单外层只负责提交、记录标识和默认值。币种、来源和费用类型下拉统一维护，保留出售费用关联及中英文说明。
- 投入小计直接从购买价格和评级费用计算，移除重复 React 状态、更新副作用、表单属性和草稿存储字段；草稿恢复不会用过期小计覆盖实际金额。移除已退役勾选项的事件处理。
- 持仓交易、费用和估值类型复用财务事实定义；平均成本、金额精度、历史截点与核算结果保持不变。
- 全局样式按原规则顺序拆为 `foundation/controls/gallery/workflows` 四个模块，由入口 CSS 依次引入。
- 发布与独立验包共用 `verifyPackagedApplication`；检查版本、Prisma、Next.js、SWC、文件卫生，打包时额外核对当前构建标识。目录与 ZIP 使用同一禁入规则；付费 AI、实机安装、真实照片和 Playwright 桌面验收脚本留在源码中，不进入用户分发包。
- 发布清理只替换当前版本产物和临时打包输出，保留旧版本文件；真实打包桌面启动与安全设置检查纳入发布流程。Windows 验收脚本支持指定上一版本，使用独立应用标识与专属目录。
- 定向升级 `sharp` 至 0.35.5、`source-map-js` 至 1.2.2，分别对应 [librsvg 修复公告](https://github.com/advisories/GHSA-wq5f-xc86-pv6w) 与 [source-map 修复公告](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)。
- 现行中英文 README、路线图、应用内更新说明、财务规则、备份、分享、主题与签名规范统一到本版。分散的 2026-10-10 开发记录合并到本页，旧版本发布事实保持原样，双语 README 保留全部 30 个历史版本。

冻结的旧核算实现用于独立结果对照，工作进程由运行时路径启动；两者均有实际用途，保留。个人数据、备份、加密配置及历史分发文件不作为冗余源码清理。

数据库结构标记仍为 `1.3.0`，核算版本为 `physical-position-v2`，AI 加密配置 v5、分享协议 v3、备份清单 v1。所有历史收藏已迁入当前完整格式，后续继续遵循该格式；本版只调整估值来源分类，不提供旧结构升级或重写财务事实。

## 本轮独立证据

2026-10-10 已执行的专项验收：Azure、MiniMax、DeepSeek 连接检查，Azure 合成卡图识别与真实组合分析通过，分析包含五项评分且未使用本地兜底。凭据通过现有桌面配置读取，使用隔离配置和合成收藏，没有上传真实收藏内容；付费调用不进入常规门槛。

五张真实大照片在隔离副本中完成备份、恢复、媒体完整性与模拟 ENOSPC，合计 13,712,343 字节，原图 SHA-256 未变。三个目录切换边界验证采用进程终止；不代表物理断电或硬盘掉线验收。

真实收藏来源转换已处理 25 条近期成交，保留 103 条个人估计；转换前保留 SQLite 一致性副本，除分类和派生索引外其它 24 张业务表核对一致。冻结快照只调整来源分类，金额、日期和汇率依据保持原值。

此前开发版与隔离 NSIS 实机安装/升级/便携迁移验收作为本轮开发证据保留；正式 v1.3.6 产物须通过下面的独立发布验收，不沿用开发版校验值。脱敏记录位于 `logs/development-2026-10-10/`，包括 `batch-comparison.json`、`live-ai.json`、`storage-photos.json`、`collection-source-migration.json`、`collection-source-verification.json` 和 `windows-acceptance/report.json`。
