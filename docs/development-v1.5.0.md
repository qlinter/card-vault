# Card Vault v1.5.0 开发记录

版本与范围确认：2026-10-24。按用户要求逐阶段实施、逐阶段确认，保留 AI 组合分析。早期阶段仅交付源码并做针对性验证；2026-10-25 用户追加授权全面结构整理、完整发布验证、生成安装包与便携包及 GitHub 同步，当前交付结果见文末与发布说明。

## 实施边界

不增删数据库表或字段，不迁移、重写或清理已有数据，保留备份及导入导出的兼容性。第三阶段的最新明确授权例外：删除指定的旧寻卡、心愿与分析快照记录；除此之外继续遵守原边界，具体范围与执行阶段见文末。修改页面、组件、表单交互、样式、只读范围查询与导出请求筛选、版本及说明文档；数据库及导出格式核心不变。验证使用隔离的临时收藏库。

## 第一阶段

1. 收藏首页压缩摘要；默认搜索、状态与排序，其余筛选按需展开，已应用条件可逐项移除。
2. 近期活动和原有整理操作移动到数据总览；现有任务状态和 API 保留，清单合并留到第二阶段。AI 组合分析保留在数据页。
3. 图片提前到录入表单上方；AI 与财务按需展开，非空财务草稿和校验错误自动展开。模板及批量队列在表单外统一到录入工具，避免嵌套表单；模板定位到同一录入工作区的卡片表单。
4. 自动草稿继续工作；有其他草稿时提供可展开列表。运动类型仅对无草稿、无队列且未填写的新卡沿用本机上次选择。
5. 单卡详情隐藏空档案字段、未启用属性与空备注；公开状态仍可展开查看。财务提供直接的买入、售出、估值及费用操作，图表与历史按需查看，编辑记录继续保留原有类型选择。
6. 分享改为选卡和预览保存两步。AI 文案、自定义设计与视觉微调可选；所有已有字段继续提交，草稿和撤销继续工作。
