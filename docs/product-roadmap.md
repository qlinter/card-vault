## 已完成：分享展馆

当前实现沿用独立展馆样式与主题、章节和单卡覆盖、统一渲染器、公开字段白名单、导出检查与差异报告。静态包和人工 Drop 流程保留；不因本轮清理增加托管服务。具体约束统一见[分享规范](./share-gallery.md)。

## v1.3.1 发布完成

启动和恢复修复、提醒与导出范围、增量索引、财务查询优化、当前格式清理及双语文档已纳入本批。源码门槛、包内运行、版本与 SHA-256 检查均已通过，结果登记在发布说明中；尚未线上发布。

## v1.3.2 分发完成

纳入安全依赖更新、配置完整替换、恢复副本清单校验、Windows 路径修复、计划查询优化、密集组合历史复用及大规模 CSV/XLSX 流式导出。逐月财务输出对照、千/万卡 HTTP 导出、取消清理与完整组合页基准均已完成。本轮复核进一步移除旧查询与闲置辅助函数，统一 ZIP 和内存采样，收敛内部接口及分发内容；保留独立财务对照基线和现行恢复保护。用户确认后已生成 Windows x64 未签名安装包和便携包；完整发布检查、包内卡片/分享/数据管理/流式导出、版本、分发内容与 SHA-256 验证通过。验证结果及待人工验证项统一记录在本版发布说明。

## v1.3.3 分发完成

新增 DeepSeek 配置，采用官方 deepseek-flash 模型和图像输入格式，沿用 Windows 加密存储；兼容旧版 v5 配置并保留其它服务设置。统一财务历史的金额/编辑列及持仓指标的文字/数值对齐，精简首页排序和组合栏目名称，修复结构集中度对齐、长产品线显示与售出复盘日期列。同时精简历史记录的重复估值标题、缩短首页搜索提示并减少结构卡片的空白。相关说明集中在设置的使用说明。官方依据：[V4.1 Flash 发布公告](https://deepseek.com/news/deepseek-v4-1-flash/)与[图像输入文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)。以上统一纳入 v1.3.3，安装包与便携包已生成并通过验证；真实 DeepSeek 调用需用户配置密钥后验证。

架构整理统一 AI 默认值、公开配置与合并规则，删除 6 个过时财务操作，拆分分享 HTML/CSS/浏览器脚本，消除两组类型循环引用，并将架构检查纳入发布门槛。保留独立财务对照基线与现有流式导出实现。源码与分发验收统一记录在 [v1.3.3 发布说明](./release-v1.3.3.md)。

## 后续优先级

| 优先级 | 方向 | 启动与验收条件 |
| --- | --- | --- |
| 暂缓 | 真实 Windows 安装升级验证 | 用户已同意暂缓；v1.3.3 分发包已生成并通过包内验证；待重新安排全新安装、覆盖升级、便携迁移和数据保留实机验证。 |
| 1 | 大数据与故障恢复 | 密集历史复用与磁盘流式导出已完成；后续按实测拆分组合查询、报表投影和渲染耗时，评估任务分页，并补充真实大照片和断电场景。 |
| 2 | 使用反馈驱动的体验改进 | 记录录入、查找和整理的实际困难；维持现有布局与字重方案，按反馈调整，不无依据再做整页改版。 |
| 3 | 数据规则扩展 | 在已有精确状态开始日期基础上扩展完整状态变更历史、更多导入字段及更细纠错流程，先明确模型与兼容要求。 |
| 暂缓 | 长期在线发布与多设备同步 | 用户重新确认需求，并具备长期托管、身份、运维与恢复条件后再规划。 |

已取消的独立批量修改入口、最近批次列表、系统摘要通知和分享“更多”菜单不再作为待开发事项。没有独立手机版本计划；分享网页仍需适配手机浏览器。

## 持续规则

财务改动复用[统一核算](./financial-history-model.md)，缺失值不能当零；数据库与媒体变更须具备快照、回滚或冲突保护。保留用户原文、表单输入、筛选和返回上下文。测试使用隔离数据；统计覆盖率仅代表实际加载模块。后续版本号在范围确认及发布收口时确定，中英文路线图同步维护。
