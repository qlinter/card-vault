# Card Vault v1.5.0 更新说明

日期：2026-10-25。第一、二阶段及第三阶段 3A、3B、3C、全面复核与代码结构整理已实施。本轮交付源码、Windows 安装包与便携包，并同步 GitHub。

## 第一阶段

- 收藏首页使用一行摘要，首层筛选保留搜索、收藏状态与排序；高级筛选完整保留，并显示可移除的已应用条件。
- 近期活动和原有整理提醒移到数据总览，提醒状态、忽略、延后及撤销继续使用原有数据。AI 组合分析保留在数据页。
- 新增卡片提前展示图片；财务、AI 工具、模板和批量队列按需展开。草稿继续自动保存，有其他未完成草稿时显示可展开的列表；新建卡片可沿用上次运动类型。
- 单卡管理详情只列出已填写的非必要档案信息；详情与编辑页统一使用“新增财务记录”入口，录入类型依次为买入、卖出、费用、估值，图表和历史按需展开。
- 分享缩为选卡、预览保存两步；AI 文案辅助改为可选工具，样式提供视觉默认值，自定义设计、视觉参数、背景和封面按需展开。已有章节、重点卡、故事、展示参数和草稿继续保留。

阶段确认前进一步统一首页摘要基线、数据概览字号及第一阶段标题层级，修复展开财务区域的嵌套网格压缩；单卡单图充分使用图片列宽，分享编辑摘要与分区留白同步收紧。

## 第二阶段

- 主导航归并为收藏、展示、数据；设置位于右侧工具区，心愿与寻卡从收藏进入，分享集从展示进入。
- 整理收藏统一使用数据明细的事实问题清单，补齐资料后自动移出；送评、待售跟进和已处理提醒在同页按需展开，保留现有处理状态及撤销。
- 收藏页导出直接复用已应用筛选、现有网格或列表与选卡结果；支持选择已加载或全部结果，返回详情保留勾选。设置保留导出全部数据，取消重复的导出搜索、分页与卡片列表。CSV/XLSX 字段、公开导出隐私规则和财务流水格式不变。
- 新增卡片的展示描述与备注并列第一行，标签独占下一行。

第二阶段修整：明细以统一列表和状态选择整合全部、持仓与出售；整理直接列出当前范围全部问题。新建分享集标题、AI 入口、展示页分享入口及设置/语言按钮同步优化，自动草稿继续静默保存。

设置追加精简：移除“尚无成功备份记录”的提示，取消定时自动备份、保留数量设置及自动清理历史备份。保留手动备份、恢复前安全副本和已有备份兼容性；旧自动备份配置不再生效，也不清理旧配置或已有副本。

## 复核修复与结构整理

版本复核修复：分享草稿在收到保存成功确认后才清理，中断提交仍可恢复；编辑页的财务变更同步收藏状态，并保留其他财务类型及档案的未提交输入。AI 切换服务或修改 Endpoint 后忽略旧请求结果，保存有明确反馈，中英文自定义配置交互一致。分享选卡按展开分组分批显示并使用缩略图；编辑页只读取费用关联所需的卖出记录。

- 删除无调用的旧提交按钮、首页状态计数及比较加载组件，同时移除专属样式。
- 数据页导航与展示辅助独立于聚合计算，组件直接使用明确的类型模块；应用说明内容与页面渲染分开维护。
- 旧寻卡与分析历史清理共用事务、安全副本、版本复核及回滚实现，原授权范围与顺序不变。
- 安装包运行脚本使用一份白名单，构建及产物检查共用；测试从源码侧验证包内应用，开发、测试与发布工具不进入分发包。
- Electron 更新至 42.11.18，同时更新 fast-uri、undici、zod 的兼容修复版本。Electron 补丁包含[官方证书安全修复](https://github.com/electron/electron/security/advisories/GHSA-jr5w-w6x2-84p9)；本轮依赖审计已清零。

## 数据边界

不增删数据库表或字段，保留卡片导入导出及备份格式兼容性。按用户最新明确授权，例外允许一次性删除旧寻卡、心愿及分析快照、关联视图记录；旧关键词/心愿 CSV 清单功能随关联流程退出。卡片、图片、财务、公开状态、分享集、提醒及已有备份不在清理范围。初始化和数据库结构脚本未修改。

验证结果和限制记录在[开发记录](./development-v1.5.0.md)。
