# Card Vault v1.2.0 更新说明

> 历史版本记录：仅描述该版本发布时的行为和验证，不代表当前源码或可用下载。当前状态见[文档索引](./README.md)。

发布日期：2026-08-26。

v1.2.0 汇总 v1.1.1 正式发布后的全部开发内容，核心是将确定性的收藏统计扩展为独立“组合中心”，并完成首页、展示、图片操作、数据库升级和工程结构收口。

## 组合中心

- 新增独立“组合中心”页面和始终显示的主导航、首页入口。
- 按 CNY/USD 独立展示持仓估值、剩余成本、已实现盈亏、未实现盈亏和总盈亏，不进行隐式汇率换算。
- 活动趋势按“买入 / 评级 / 出售”统计，并把买入、评级和出售相关费用归入对应口径。
- 财务历史趋势按月末事实重建组合估值、剩余成本、已实现盈亏和未实现盈亏。
- 活动趋势和财务历史支持近 12 个月、近 24 个月及全部历史；12 个月无需横向滚动，更多月份按需滚动并提供逐月悬停明细。
- 提供 30/90/180 天真实估值变化，按目标日期前的最新估值和当时持仓数量计算。
- 收藏结构支持卡片主体、运动、品牌、Team、年份、产品线、评级机构及新秀、签名、Patch、限量属性，并提供首页筛选跳转和币种切换。
- 提供高价值持仓、高成本持仓、已售卡片复盘、估值来源及数据待完善清单。
- 数据待完善覆盖所有收藏状态；“已售”和“目标卡”默认数量为 0 但允许修改，估值超过 360 天记为过期。
- 组合栏目支持本机持久化拖拽排序，底部半宽栏目可同时调整上下和左右顺序。
- 百分比统一为最多两位小数，保留原本合理的一位或两位精度。

## 收藏视图、快照与比较

- 收藏视图保存当前首页筛选范围，便于重复打开核心收藏、待评级、在售或其他自定义范围。
- 时间点快照保存筛选范围、采集时间和完整确定性统计；删除收藏视图不会删除既有快照。
- 当前范围、实时收藏视图和历史快照可以任意配对比较卡片数量、分币种财务和主要/扩展结构变化。
- 视图与比较区域与当前静态组合数据显著分区、默认折叠，并统一保存视图和保存快照的操作层级。
- 一键备份和恢复完整保留收藏视图、时间点快照及其关联关系。

## 首页与展示体验

- 首页取消独立大标题区域，“新增卡片”移动到筛选操作区，“组合中心”入口保持常驻。
- 从“显示更多”后的卡片进入详情再返回时，恢复对应的已展开数量，不再回到折叠状态。
- “球员姓名”统一改为更适用于个人、团队及其他卡面的“卡片主体”；相关搜索、统计和展示文案同步调整。
- 展示页折叠状态改为受容器约束的等宽单行布局，最右侧主体不会溢出，长名称显示省略并保留完整悬停标题。

## 图片旋转

- 录入、修改和展示页面均支持向左或向右旋转图片。
- 每次操作严格沿点击方向连续旋转 90°，跨越 0° 时不会反向跳转。
- 保存的是 `0/90/180/270` 旋转元数据，原始图片文件不重新编码；展示页临时旋转不会修改保存结果。
- 普通单卡上传继续保留原格式，批量录入队列继续按既定规则预处理为 WebP。

## 数据库与备份

- 当前数据库基线升级为 v1.2.0，新增 `PortfolioSavedView`、`PortfolioSnapshotRecord` 和 `CardImage.rotation`。
- v1.1.1 数据首次启动或从备份恢复时，会在数据库相邻目录创建 SQLite 一致性快照，再一次性补齐新结构。
- v1.1.0 备份仍可先完成既有持仓与费用归属升级，再补齐 v1.2.0 结构；更早数据库需先通过对应旧版升级。
- 已符合 v1.2.0 基线的数据只执行结构与完整性校验，不重复迁移、回填或改写图片。
- 恢复继续在应用运行期间完成，不退出或重启 Electron；暂存区校验失败不会替换当前数据。

## 工程收口

- 合并组合统计中的金额精度处理、金额与日期展示格式，以及统计快照和数据质量清单共用的质量判断规则。
- 删除已被连续角度实现替代的旧图片旋转函数，保持表单提交只接收标准直角方向。
- 组合分析、组合中心和备份恢复继续复用同一查询、持仓核算和数据库基线，不复制财务算法。
- 将组合中心按视图比较、趋势、结构和数据质量拆分为独立组件，降低单文件复杂度。
- 将分享编辑器样式从全局样式表迁移到组件级 CSS Module，避免编辑器样式影响其他页面。
- 新增首页、卡片录入、组合中心、分享编辑器和设置页的桌面端与移动端视觉回归基线。
- Windows 发布前自动清理 Prisma 临时引擎；打包后拒绝临时引擎、应用 Source Map 和超预算产物。
- 统一项目版本、锁文件、中英文 README、路线图、备份、财务、分享和 Windows 签名文档。

## 升级说明

- 建议升级前执行一次应用内“一键备份”。
- 可直接覆盖安装 v1.1.1；收藏数据目录不会因安装程序覆盖而被主动删除。
- 升级后建议检查卡片图片、组合中心、收藏视图和时间点快照，再执行一次数据健康检查。
