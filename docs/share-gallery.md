# 分享展馆规范

适用源码版本：`1.3.0`。本文件是分享展馆当前唯一的产品与工程规范；早期“编辑器 2.0”和“展馆 3.0”阶段文档已合并到这里。

## 产品边界

- 分享集与本地展示页相互独立，只包含用户主动选择的卡片。
- 预览、通用静态包和 Cloudflare Drop 临时包使用同一个渲染器。
- 导出严格使用公开字段白名单，不包含价格、成本、购买渠道、私人备注、AI Key 或本地数据库路径。
- Cloudflare Drop 仅作为人工临时发布渠道；应用不保存临时 URL 或认领链接。
- 当前不提供二维码、永久托管、在线更新、撤回、访问统计或账户权限。

分享列表将预览、编辑、导出、删除并列显示，不设置“更多”菜单；四个按钮的字号与高度一致。新建分享集位于列表上方右侧。

## 制作流程

分享集固定为四步：

1. 选择球星卡。
2. AI 生成。
3. 内容修改。
4. 确认保存。

步骤页只保留标题、状态和必要操作，不重复解释已经由控件表达的内容。主要编辑工作集中在第三步，并分为“基础内容、视觉设计、展馆章节、单卡展示”四个工作区。

## 展馆样式与主题

“展馆模板”和“展馆版式”统一为“展馆样式”：

| 展馆样式 | 内部结构 | 适用内容 |
| --- | --- | --- |
| 藏家聚光 | 沉浸舞台 | 明星卡、稀有卡和少量核心收藏 |
| 典藏志 | 典藏档案 | 生涯记录、系列收藏和长篇叙事 |
| 主场阵容 | 竞技主场 | 球队、赛事和多卡组合 |

样式负责结构版式、背景焦点、文字面板不透明度、字体、内容密度、图片构图和字号预设。主题只负责颜色与背景素材，和样式独立选择。修改主题或微调视觉参数不会清除当前样式；再次选择样式时才重置该样式管理的参数。

自定义背景图和封面图始终独立于样式与主题。文字面板不透明度范围为 10%–90%，所有内置主题和自定义背景统一使用同一个透明度变量。

## 内容与编辑能力

- 标题、副标题、封面介绍、展馆叙事、收藏亮点和主题分组均可编辑。
- 章节支持描述、结构选择、卡片分配、拖拽排序以及键盘上移/下移。
- 单卡可覆盖展示标题和公开故事；每个展馆最多标记 6 张重点卡。
- 编辑器保留最多 80 步撤销/重做，并按分享集隔离本机自动草稿。
- 新上传的背景和封面在保存前即可进入实时预览。

## 展示协议与兼容

`SharePresentation` 当前协议版本为 3，继续存放在 `ShareCollection.presentationConfig` JSON 字段中，不需要 Prisma 或 SQLite 迁移。

- `templateId` 保留为内部兼容字段，对应界面中的“展馆样式”。
- `featuredCardIds` 保存最多 6 张重点卡。
- 旧版本或缺少 `templateId` 的配置读取为 `custom`，原有布局、背景焦点、字体、密度、图片构图和字号继续保留。
- 历史文字面板不透明度低于当前可见下限时归一为 10%。
- 旧分享集缺少重点卡数据时自动使用空数组。

v1.3.0 调整封面卡图比例、背景文字面板及标题层次；完整卡图构图保留评级壳和编号边缘，裁切模式继续可选，不修改旧分享集的字段协议。

## 预览与响应式

- 编辑器实时预览提供桌面 1440px、平板 768px、手机 390px 三档视口。
- 独立预览页使用接近完整窗口的居中画布，最大宽度 1600px，预览框高度至少 640px。
- 821–1024px 调整标题、双栏比例、卡片网格和数据看板；820px 以下使用单栏结构并取消不适合窄屏的立体变换。
- 页面边距、内容宽度、封面安全区、章节间距和标题行宽使用共享设计变量。
- 应用内预览允许同源主题和媒体资源，但继续禁止表单提交与顶层导航。

## 静态导出

- 每张卡片生成最长边不超过 1600px 的 WebP 展示图和最长边不超过 640px 的 WebP 缩略图。
- 自定义封面最长边不超过 1600px；背景图最大宽度 2560px。
- 每个结构化章节生成 `sections/*.html`，每个卡片主体生成 `subjects/*.html`，单卡详情位于 `cards/*.html`。
- 首页立体轮播最多展示 24 张精选卡；完整馆藏首次显示 48 张，后续每次增加 48 张。
- 首屏图片预加载，其余图片使用响应式 `srcset`、原生懒加载和异步解码。
- 无法解码的历史图片保留原文件并写入非阻断提醒，不因单张图片中止整个导出。

## 发布质量

每次导出都会：

- 检查断链、私密字段、文件数量和单文件大小。
- 检查页面语言、视口、主内容区、一级标题、图片替代文本和按钮可访问名称。
- 写入格式版本 3 的内容清单与检查摘要。
- 生成 `EXPORT-DIFF.md`，仅比较同一分享集上一次相同模式的导出。

桌面浏览器测试覆盖新建、编辑、实时预览、独立预览、背景取消、重点卡故事、导出以及中英文界面；390px 模拟视口只验证分享预览和生成网页，不代表已有手机应用。视觉基线覆盖分享编辑器和独立预览页，当前测试结果见[开发进度](./v1.3.0-implementation.md)。
