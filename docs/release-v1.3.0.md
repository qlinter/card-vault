# Card Vault v1.3.0

> 本页保留 2026-09-07 发布时的行为、验收和产物信息；不代表当前格式兼容范围。后续修订、清理和优化已统一纳入 [v1.3.1](./release-v1.3.1.md)。

2026-09-07。包含相对 v1.2.1 的财务、可靠性、本地数据管理与界面更新。经用户明确确认，Windows x64 安装包与便携包已重新生成并完成验证。本次为未签名构建，文件保存在本地 dist，尚未上传到线上发布渠道。

## 最终更新内容

- 财务统一为一份实物数量，支持 CNY/USD 混合付款与跨币出售；人工汇率按业务日期使用，首页、详情、组合及趋势共享核算。缺失成本、汇率、估值明确显示不完整，冻结快照保留原依据。
- 备份、恢复、清理和 AI 设置重启共享操作锁；备份暂停服务并检查数据库与媒体，增加 SHA-256 清单和迁移报告。孤立媒体移入恢复副本，日志使用用户可写目录并可降级。
- 界面改用显式翻译，保护主体、卡名、标签和备注原文；档案与财务表单失败保留页面内输入。
- 首页每次查询 24 张卡片，统计和全局财务排序使用可重建索引；组合每批读取 250 张，取消原 5000 张硬限制。
- 设置中的数据统一管理存储、备份与恢复、导入、导出。CSV/XLSX 支持映射、重复策略、预演、逐行重试和冲突保护撤销；档案导出与私密 XLSX 财务流水分开。独立批量修改入口和最近批次列表已取消。
- 计划提供 180 天估值/送评/在售提醒、资料待补、7/30 天摘要、心愿单与原币预算。心愿单的“新增”和“列表”独立折叠；系统摘要通知已取消。
- 首页与展示使用紧凑的卡片/列表切换；一级页面取消重复大标题；组合分析、新建分享集入口重新布局。设置中的数据与使用说明向下展开，说明集中管理。
- 分享的预览、编辑、导出、删除并列且字号与高度一致，无“更多”菜单。展馆强调完整卡图、背景上的文字可读性，并保持预览与导出共用渲染器。
- 导出卡片信息直接进入详情，返回后恢复展开、搜索、页码、视图和勾选。路径文字与“选择文件”保持相同常规字重；其它已确认字重和布局保留。

## 本轮代码与文档整理

清除退役批量任务创建接口、最近批次查询、旧首页估值统计、无调用操作包装及失效样式；既有批次仍保留恢复兼容。导出从任务执行模块分离，只为私密 XLSX 加载财务流水。文件 SHA-256 实现统一，避免校验大文件时一次性读入全部内容。备份清单增加表数量完整性验证，导入/导出补齐无效输入检查。

修复 Git 忽略规则误排除设置数据页面的问题，并增加源码完整性检查；更新两个存在公告漏洞的打包工具依赖，CI 审计覆盖全部依赖。

README、现行规范、应用说明、中英文路线图和开发进度按最终行为整合；不再堆叠已撤回方案和旧验收次数。

## 兼容与范围

数据库基线仍为 `1.3.0`，核算版本为 `physical-position-v2`。支持的旧库通过增量初始化和安全快照升级；不删除用户数据，不回灌旧浮点汇总，不扩展更早不受支持数据库的升级路径。旧批次和已退役通知字段保留兼容用途，不重新启用相关界面。

CSV/XLSX 不是完整备份。送评和在售时长以最近档案修改日近似；长期托管与多设备同步暂缓，现有静态包/人工 Drop 发布保留。产品交付平台是 Windows；窄视口测试仅针对分享网页。
