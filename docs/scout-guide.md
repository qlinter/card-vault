# 寻卡使用与数据规则

当前源码版本 v1.5.0。寻卡包含两个独立区域：上方心愿单、下方跨站查询。

## 跨站查询

输入关键词，点击卡淘、eBay 或 130point 打开外部网站，也可复制关键词。卡淘与 eBay 使用当前输入构造查询地址；130point 打开其查询页面后自行粘贴。外链在新窗口打开。

查询不保存关键词或查询历史，不关联心愿或卡片。卡片详情仍可将卡片信息带入查询框，这只是填写搜索文本，不建立关系。

## 心愿单

名称为唯一必填项；主体、预算及币种、备注为可选。可新增、编辑、删除，按名称、主体和备注搜索，每页 20 条。默认按新增时间倒序排列。

预算为原币金额，区分未填写与零，最多两位小数，不影响卡片成本、估值或财务流水。保存失败保留输入；保存成功但刷新失败时只需刷新列表，不重复提交。心愿草稿按收藏库保存在本机，关闭编辑或刷新后可继续。

不再提供关键词管理、关键词关联、优先级、目标日期、目标数量、入藏、卡片绑定、进度、状态归档或独立清单导出。

## 历史记录清理

按用户本轮明确授权，首次进入新版寻卡或使用新版心愿接口时，一次性删除旧关键词、旧心愿、额外属性以及关键词和卡片关联。清理前保留一致性数据库安全副本至数据库目录的 `.recovery/scout-v1.5.0/`，界面不提供旧记录查询入口。

清理和数据库版本标记在同一事务提交；出错则整体回滚。版本标记使用数据库现有的 SQLite 元数据，未新增表或字段。后续进入不会删除新心愿；新版备份恢复后也不会再次清空新记录。旧版备份若重新使用新版寻卡，其旧寻卡历史仍会按此规则清理。

仅清理寻卡与心愿的五张现有表中的记录，不删除卡片、图片、财务流水、分享或备份。旧浏览器寻卡草稿和导航缓存同时移除。数据库表和字段、卡片导入导出格式及备份清单规则保持原样。
