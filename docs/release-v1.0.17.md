# Card Vault v1.0.17 更新说明

发布日期：2026-08-16。

## AI 设置扩展

- AI 设置支持新增、命名、编辑和删除多套 OpenAI Chat Completions 兼容的自定义服务，不再限制为单一“自定义 AI”。
- 自定义服务保存后直接显示用户设定的名称，并分别维护聊天 Endpoint、模型列表 Endpoint、模型 ID 和加密 API Key。
- API Key 统一采用常见的 `Authorization: Bearer` 方式发送；允许本地无鉴权服务留空 API Key，不再要求用户配置低频的 Header 与前缀字段。
- Azure OpenAI、MiniMax、前端设置页和 Electron 主进程共用同一套配置规范化与旧配置迁移规则，减少 Endpoint 和默认值不一致。

## 组合分析稳定性与报告升级

- 限制发送给模型的组合快照体积和高基数字段数量，保留完整总数、财务覆盖度、集中度和重点持仓统计，降低长文本导致的失败风险。
- AI 客户端支持瞬时限流和网络错误重试，并兼容模型对 `max_completion_tokens`、`max_tokens`、`temperature` 与 JSON mode 的不同要求。
- 增强 JSON 提取和思考文本清理，兼容 Markdown 代码块、响应外围说明和部分兼容服务的非标准输出。
- 将组合分析统一为五个不重复的维度：组合结构、财务记录、收藏特征、估值时效和档案完整度。
- 每个维度统一展示评分、解释、数据充分度、主要发现和可追溯证据；报告补充关注事项和按优先级排列的整理行动建议。
- 对结构正确但内容不足的 AI 报告使用本地统计补全；所有远程请求均失败时，展示完整的本地确定性保底报告，避免只显示综合评分、“暂无判断”或整页失败。
- 组合分析维度协议集中维护，提示词、类型、结果校验、内容补全和前端展示使用同一份定义。

## 卡片与财务历史体验

- 将卡片字段统一显示为 `Team`，使其可以同时表达足球俱乐部、篮球队、F1 车队等不同运动组织。
- 财务历史取消“旧数据迁移”“已纠错”“人工录入”等编辑状态展示；交易、费用和估值的单条操作统一显示为“编辑”。
- 修复从筛选后的卡片列表进入编辑页或修改财务历史后，点击返回丢失筛选、排序和分页状态的问题。
- 页面跳转统一携带并校验返回上下文，避免不受信任的返回地址进入导航流程。

## 代码结构与冗余清理

- 统一 AI 配置规范化和完整性校验，删除前端、API 路由与 Electron 主进程中的重复实现。
- 三个本地图片读取路由共用安全文件响应处理器；分享编辑器复用卡片公共字段映射。
- 重构组合分析归一化和本地保底报告，将金额边界、置信度、数据充分度和协议键集中处理。
- 删除无调用的存储路径兼容导出，以及约 700 行未被页面使用的旧视觉样式，并合并重复 CSS 选择器。
- Windows 发布移除与 NSIS 重复的显式 `dir` 目标；NSIS 生成的 `win-unpacked` 继续用于打包后冒烟测试和便携 ZIP。
- Windows 发布脚本在本机 NSIS 缓存可用时自动传入 `ELECTRON_BUILDER_NSIS_DIR` 和 `ELECTRON_BUILDER_NSIS_RESOURCES_DIR`，避免工具链自动解析在受限网络环境下卡住。
- Windows 发布脚本会在打包前修正本地 electron-builder 的 NSIS 临时安装器输出名，避免未签名本地发布中临时文件占用导致最终安装器无法覆盖。
- 便携 ZIP 改用 .NET `System.IO.Compression.ZipFile` 生成，避免 PowerShell Archive 模块不可自动加载时中断发布。
- 保留数据库历史迁移和独立静态分享渲染器等具有明确兼容职责的模块，不删除真实用户数据所需的迁移路径。

## 质量与兼容性

- 自动化测试增加到 97 项，覆盖多套自定义 AI 迁移、AI 请求兼容与重试、组合分析完整协议、本地保底报告、筛选上下文、财务历史、存储迁移和分享导出。
- 发布检查继续包含 UTF-8、版本元数据、TypeScript、生产构建、卡片与分享 HTTP 端到端流程、打包后运行时健康检查和发布产物校验。
- v1.0.17 不新增 Prisma 数据库表或迁移，v1.0.16 数据和备份可以直接升级使用。
- 安装新版不会主动删除收藏数据；升级前仍建议通过设置页执行一次完整备份。
