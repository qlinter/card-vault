# Card Vault 1.3.0 开发说明

本次为统一财务调整批次；数据库基线为 1.3.0，核算版本为 `physical-position-v2`。本文件描述源码变更，安装包和便携包须另行生成后才能分发。

- 一笔交易支持 CNY/USD 混合付款或收款，实物数量仅计算一次，支持跨币出售与费用。
- “财务”位于“AI”之后，可折叠；主币种独立保存，汇率仅强制填写数值与生效日期，说明可选，历史记录可编辑、删除且不显示“使用中”标识。
- 首页、详情、组合和历史趋势统一核算；直接报价优先，缺失成本、汇率或估值不再解释为零收益。
- 快照冻结核算版本及汇率依据，AI 使用确定性报表和完整性提示。
- 一键备份暂停本地服务并校验媒体引用，防止数据库与图片不一致却报告完整成功。
- 地球图标打开可选语言菜单，一级导航在桌面右对齐。
- 首页数字样式统一；持仓财务扩展为九项指标。历史与活动图表使用全宽，从实际业务月份开始，标签过密先抽稀，再按需滚动；财务历史显示逐月估值覆盖数，允许部分估值，未实现盈亏只扣除对应已估值持仓成本。活动图仅展示买入/出售金额与张数。
- 单卡财务历史移除顶部核算说明；设置中的“财务”提供独立中英文计算规则页；持仓财务及 AI 报告隐藏汇率明细，AI 报告移除顶部核算说明和财务设置链接。

完整规则与验算例见[财务模型](./financial-history-model.md)。更早旧数据库不新增升级支持，不自动替换或清空用户数据。

## 验证结果

- Lint、TypeScript、UTF-8、文档链接及版本元数据检查通过，生产构建通过。
- 224 项自动测试通过，行覆盖率 93.12%；覆盖付款组成、数量、费用、收益、汇率、快照和备份。
- 68 项桌面/手机 UI 测试通过，14 项视觉基线重新严格比对通过。
- 卡片财务流程、分享导出与本地会话安全 HTTP 集成测试通过。
- 对当前 1.2.0 数据库的只读一致性副本执行新结构初始化，93 张卡片、187 张图片引用及全部原有交易、费用、估值逐项保持不变；该初始化验证未修改用户原数据库。另按用户确认，将 Senna 的购买日期从 2016-01-15 更正为 2026-01-15，交易日期与卡片购买日期保持一致。
