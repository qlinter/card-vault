<a id="release-v1-5-2--2026-11-07-版本内更新"></a>
### 2026-11-07 版本内更新

- 删除保护：确认页记录档案、图片、交易、费用、估值和关联记录的版本，在同一事务中核对并删除；发生变化时保留数据并返回详情页，需核对最新内容后重新确认。
- 证书号匹配：精确证书号与最近同主体候选独立查询，精确匹配优先展示，按卡片 ID 去重，仍最多显示五项；仅填写证书号也会触发检查，不阻止合法的独立实物录入。
- 图片校验：JPG、PNG、WebP 保存前完整解码，最多 8000 万输入像素；拒绝损坏、截断和超大像素文件，合法原图字节保持不变。所有使用公共上传入口的卡图、封面、背景及识别图片遵循相同规则。
- 未备份状态：成功读取当前收藏库的备份设置且无记录时显示“当前收藏库尚无成功备份记录。”；加载中、读取失败或无桌面备份接口时不误报，首次成功备份后切换为最近备份状态。

本次不加入新用户体验设计，不修改数据库结构，不迁移或重写既有收藏、财务和图片，历史损坏图片不自动处理。沿用 v1.5.2 数据库与备份格式。

本次安装包 `card-vault-1.5.2-setup.exe`、便携包 `card-vault-1.5.2-portable.zip` 及构建／校验清单已重新生成并通过完整发布验证，沿用现有 v1.5.2 GitHub Release 与下载入口。

<a id="release-v1-5-2--本版功能与修复"></a>
### 本版功能与修复

- 收藏回顾：从统计页进入并保留当前范围，按年／月及购入／录入口径自动切换数据，无切换动画。年视图按月、月视图按自然周展示活动；支持临时调整标题和最多六张代表卡片，不保存回顾历史。
- 回顾长图：标题旁直接生成并下载 PNG，默认排除私密卡片并重新计算统计；不输出财务与私人备注。页面和长图共用统计定义及活动分桶。
- 沉浸式赏卡：从展示“浏览”或回顾的赏卡入口进入。提供暗室聚光、白盒美术馆、暖纸典藏、月光展厅四种风格；支持构图、灯光、画幅、顺序／随机、首图／全部、1–3600 秒间隔、缩放、旋转及展馆独立全屏。柔和切换默认启用并尊重减少动画偏好；设置可保存，退出恢复原页面。
- 版式与字体：同级文字和同类控件遵循公共规范；统计范围为小号状态，收藏回顾与查看卡片并排，组合分析紧邻组合总览。
- AI 设置：删除自定义配置改用内联确认并恢复焦点，删除后继续编辑，无需重启。

<a id="release-v1-5-1--ai-网络与代理"></a>
### AI 网络与代理

支持设备本机保存的自动、直连和手动 HTTP/HTTPS/SOCKS5 代理、认证及绕过规则。自动模式按服务地址读取环境变量和桌面系统/PAC 规则；不按模型名猜测线路，不进行后台网络探测。

支持 IPv4/IPv6 网段绕过、系统有序候选和系统明确的 DIRECT；每次重定向重新分流，跨域去除私有 Header，拒绝 HTTPS 降级并保留证书校验。主动连接测试显示脱敏线路结果，区分地址解析、连接、认证和证书错误；文本测试不代表图片识别能力或准确率。

读取模型、连接测试、识图、组合分析和分享文案的请求按各自生命周期传递取消。离开分享编辑页会取消在途文案生成及格式修复。模型或认证设置变化后取消旧设置请求；选择模型仍保留已读取的模型列表。

<a id="release-v1-3-6--本版本更新"></a>
### 本版本更新

- **大收藏量**：组合每批读取 250 张卡片，完成计算后释放原始历史，仅保留汇总、月度曲线、质量清单及排行候选；同次计算复用卡片财务事实。10,000 张卡片、360,000 条估值交错对照各四次，峰值堆内存中位数由 270.5 MiB 降至 129 MiB，下降约 52%；耗时 7,599.5 ms 与 7,512 ms，基本持平。结果与原实现逐项一致，不将内存改善解释为整页提速。
- **恢复可靠性**：切换数据目录前持久化操作记录。原目录移动后、新目录切换后及最终校验后模拟进程退出，再启动均恢复正确目录；验证前的失败保留原数据，验证成功后的中断保留恢复数据。非法记录路径被拒绝，写入磁盘不足即时回滚。
- **编辑返回**：返回上一页跳过卡片与分享的编辑状态，也跳过编辑前后的同一详情页。筛选 → 详情 → 编辑 → 保存或取消 → 返回，会回到原筛选结果；刷新、连续取消、浏览器存储不可用时仍保留有效返回路径。
- **交易录入**：每笔交易填写一种币种，移除另一币种付款/收款和“金额尚不完整”选项。新增与编辑金额按完整金额保存，0 表示零金额。旧草稿勾选值忽略；历史未知金额和历史附加付款保留事实，金额更正后转为已知；初始购买价格留空仍保留未知成本，缺失值不自动变成零。
- **估值来源**：四个平级选项为“个人估值、卡淘成交、eBay成交、Others”，详情记录与组合分布使用相同显示。数据库保持 `个人估计/卡淘/eBay/Others`，历史“近期成交”转为“卡淘”，“平台报价”归入“Others”；草稿、模板、导入批次和冻结快照中的分类同步调整。恢复时先校验原清单，仅转换暂存副本并重建清单，原备份保留。

v1.2.0 汇总 v1.1.1 正式发布后的全部开发内容，核心是将确定性的收藏统计扩展为独立“组合中心”，并完成首页、展示、图片操作、数据库升级和工程结构收口。

<a id="release-v1-2-0--组合中心"></a>
### 组合中心

- 新增独立“组合中心”页面和始终显示的主导航、首页入口。
- 按 CNY/USD 独立展示持仓估值、剩余成本、已实现盈亏、未实现盈亏和总盈亏，不进行隐式汇率换算。
- 活动趋势按“买入 / 评级 / 出售”统计，并把买入、评级和出售相关费用归入对应口径。
- 财务历史趋势按月末事实重建组合估值、剩余成本、已实现盈亏和未实现盈亏。
- 活动趋势和财务历史支持近 12 个月、近 24 个月及全部历史；12 个月无需横向滚动，更多月份按需滚动并提供逐月悬停明细。
- 提供 30/90/180 天真实估值变化，按目标日期前的最新估值和当时持仓数量计算。
- 收藏结构支持卡片主体、运动、品牌、Team、年份、产品线、评级机构及新秀、签名、Patch、限量属性，并提供首页筛选跳转和币种切换。
- 提供高价值持仓、高成本持仓、已售卡片复盘、估值来源及数据待完善清单。
- 数据待完善覆盖所有收藏状态；“已售”和“目标卡”默认数量为 0 但允许修改，估值超过 360 天记为过期。
- 组合栏目支持本机持久化拖拽排序，底部半宽栏目可同时调整上下和左右顺序。
- 百分比统一为最多两位小数，保留原本合理的一位或两位精度。

<a id="release-v1-2-0--收藏视图快照与比较"></a>
### 收藏视图、快照与比较

- 收藏视图保存当前首页筛选范围，便于重复打开核心收藏、待评级、在售或其他自定义范围。
- 时间点快照保存筛选范围、采集时间和完整确定性统计；删除收藏视图不会删除既有快照。
- 当前范围、实时收藏视图和历史快照可以任意配对比较卡片数量、分币种财务和主要/扩展结构变化。
- 视图与比较区域与当前静态组合数据显著分区、默认折叠，并统一保存视图和保存快照的操作层级。
- 一键备份和恢复完整保留收藏视图、时间点快照及其关联关系。

<a id="release-v1-2-0--首页与展示体验"></a>
### 首页与展示体验

- 首页取消独立大标题区域，“新增卡片”移动到筛选操作区，“组合中心”入口保持常驻。
- 从“显示更多”后的卡片进入详情再返回时，恢复对应的已展开数量，不再回到折叠状态。
- “球员姓名”统一改为更适用于个人、团队及其他卡面的“卡片主体”；相关搜索、统计和展示文案同步调整。
- 展示页折叠状态改为受容器约束的等宽单行布局，最右侧主体不会溢出，长名称显示省略并保留完整悬停标题。

<a id="release-v1-2-0--图片旋转"></a>
### 图片旋转

- 录入、修改和展示页面均支持向左或向右旋转图片。
- 每次操作严格沿点击方向连续旋转 90°，跨越 0° 时不会反向跳转。
- 保存的是 `0/90/180/270` 旋转元数据，原始图片文件不重新编码；展示页临时旋转不会修改保存结果。
- 普通单卡上传继续保留原格式，批量录入队列继续按既定规则预处理为 WebP。

<a id="release-v1-2-0--数据库与备份"></a>
### 数据库与备份

- 当前数据库基线升级为 v1.2.0，新增 `PortfolioSavedView`、`PortfolioSnapshotRecord` 和 `CardImage.rotation`。
- v1.1.1 数据首次启动或从备份恢复时，会在数据库相邻目录创建 SQLite 一致性快照，再一次性补齐新结构。
- v1.1.0 备份仍可先完成既有持仓与费用归属升级，再补齐 v1.2.0 结构；更早数据库需先通过对应旧版升级。
- 已符合 v1.2.0 基线的数据只执行结构与完整性校验，不重复迁移、回填或改写图片。
- 恢复继续在应用运行期间完成，不退出或重启 Electron；暂存区校验失败不会替换当前数据。

<a id="release-v1-1-1--持仓交易与收益"></a>
### 持仓、交易与收益

- 录入工作台支持填写初始数量；同一张卡可分批买入、部分出售并保留完整交易历史。
- 采用按币种独立计算的移动平均法分配部分出售成本，金额以最小货币单位存储和计算，避免浮点误差。
- 自动计算当前数量、剩余成本、平均单张成本、出售净收入、已实现盈亏、未实现盈亏和总盈亏。
- 出售数量超过当前持仓时整笔操作回滚；全部售出后状态自动切换为“已售出”，重新买入后恢复为“持有中”。
- 首页总估值按“最新单张估值 × 持有数量”计算；按产品决定，不在首页单卡缩略图显示持有数量。

<a id="release-v1-1-1--费用归属与历史记录"></a>
### 费用归属与历史记录

- 费用明确分为“计入买入成本”“计入评级成本”“从出售收入扣除”三种归属。
- 出售相关费用必须关联同一卡片、同币种的具体出售记录，只在选择出售归属时显示关联字段。
- 财务时间线直接显示每笔记录对数量、持仓成本、出售收入或估值的影响，并支持新增、编辑、删除和类型筛选。
- “＋ 新增记录”提升为财务历史标题栏主操作，点击后在标题下方直接展开录入面板。

<a id="release-v1-1-1--财务概览与图表"></a>
### 财务概览与图表

- 默认突出当前持有数量、持仓成本、当前估值和总盈亏，次要指标收纳到“成本明细”和“出售与收益”。
- 增加持仓成本阶梯线、离散估值快照、累计成本构成和盈亏构成图。
- CNY 与 USD 使用独立页签和坐标，不做自动汇率换算或混合核算。
- 组合分析与卡片详情复用同一持仓核算结果，统计过程只计算一次持仓并在各维度间复用。

<a id="release-v1-1-1--v110-数据升级与当前基线"></a>
### v1.1.0 数据升级与当前基线

- v1.1.0 数据升级前自动创建 SQLite 一致性快照；升级失败会回滚，不替换当前可用数据。
- 根据既有买入和出售记录回填持有数量；无交易时，持有/在售/送评按 1 张，已售/目标按 0 张。
- 运费与购入日期或买入交易日期同一天时归入买入，其余运费归入评级；平台费用归入出售，其他既有费用默认归入评级。
- 升级只对一份 v1.1.0 数据执行一次；恢复 v1.1.0 备份时会在暂存区重新升级，v1.1.1 备份不会重复回填。
- 删除 v1.1.0 以前的历史迁移与回填执行链路；新数据库直接创建完整 v1.1.1 基线，现有数据库只接受 v1.1.1 当前结构或正式 v1.1.0 升级结构。
- 删除开发预览数据库兼容分支，仅保留正式 v1.1.0 → v1.1.1 升级路径。

<a id="release-v1-1-1--备份恢复与本地服务"></a>

<a id="release-v1-1-0--录入工作台-20"></a>
### 录入工作台 2.0

- 新增 SQLite 录入草稿、自动保存与中断恢复；草稿只保存表单字段，不复制临时选择的本地图片。
- 保存卡片时可选择查看详情、继续录入或复制公共字段新增；复制模式不携带编号、证书、图片和财务数据。
- 新增公共字段录入模板，可创建、应用、更新和删除，并记录最近使用顺序。
- 新增疑似重复卡提示，根据球员及年份、产品线、卡号、平行版本、证书号等匹配依据给出候选，但不阻止保存。
- 从重复候选进入详情前会保存草稿；“返回上一页”会恢复真实浏览历史，并保留草稿及批量队列上下文。
- 增加保存、继续录入和队列前后切换快捷键，并在校验失败时定位首个必填项。

<a id="release-v1-1-0--批量图片与-ai-候选"></a>
### 批量图片与 AI 候选

- 新增可折叠的批量录入队列，可按选择顺序组成正反面项目，也可将每张图片作为独立项目。
- 队列图片读取 EXIF 方向，将最长边限制为 2400 像素并转换为 WebP；普通单卡上传仍保留原始图片格式。
- 单项预处理失败不会影响同批其他项目，可独立重试、移除或交换正反面。
- 保存卡片时以事务方式接管队列 WebP，成功后进入下一待录入项目；提交失败时不丢失队列图片。
- AI 批量识别只在用户主动启动后运行，结果作为持久化候选写入工作台，显示低置信字段并要求逐卡确认。

### 数据迁移与备份

- 迁移前继续创建 SQLite schema 快照；应用启动和旧备份恢复都会自动执行尚未完成的迁移。

<a id="release-v1-0-14--财务历史与首页估值"></a>
### 财务历史与首页估值

- 增加购买、售出、退款、费用和估值历史，金额使用整数最小货币单位保存。
- 卡片详情页支持新增、按币种汇总、统一时间线、纠错和删除；普通卡片编辑不再覆盖财务历史。
- 币种仅支持 CNY/USD；估值来源仅支持个人估计、近期成交和平台报价。
- 旧财务字段自动迁移为可追溯基线；所有旧估值来源统一为个人估计，非 CNY/USD 历史记录在迁移中删除。
- 首页总估值针对当前筛选出的全部卡片，每张只采用业务日期最新的一条估值，不按收藏状态排除，也不重复累计历史估值。
- CNY/USD 固定分行显示，统一使用 ISO 代码、千位分隔符和相同字号；覆盖度简写为“估值覆盖 x/y”。
- 首页组合分析直接使用交易、费用和估值历史，按 CNY/USD 分别呈现成本基础、净现金占用、可比未实现盈亏、估值时效和估值来源，不跨币种合计或假设汇率。
- 有售出记录但仍处于活跃状态的复杂仓位不计算可比收益率；现有数据无法可靠配对出售数量与成本批次，因此不虚构已实现收益。

<a id="release-v1-0-14--数据恢复与可靠性"></a>
### 数据恢复与可靠性

- 从旧备份恢复时，先在暂存目录执行全部待办迁移和完整性检查，成功后才替换当前数据。
- 恢复前继续生成当前数据安全备份；迁移或校验失败时不替换当前数据。
- 桌面启动脚本会检查依赖缺失及锁文件新旧状态，并在需要时自动安装依赖。
- 首页、组合分析、卡片财务摘要和兼容快照统一使用同一套“业务日期优先、创建时间解决同日并列”的最新估值判定规则。
- 精简重复的 Windows 发布命令入口，并将数据备份说明迁入 `docs`、更新为 v1.0.14 的恢复与历史迁移流程。
- 新增财务历史、恢复自动迁移、币种约束和最新估值计算的自动化测试。

<a id="release-v1-0-14--windows-发布签名"></a>
### Windows 发布签名

- v1.0.14 支持可选 Authenticode 签名；未配置证书时仍可直接生成安装包和便携包，不再执行强制证书验证。
- 配置 PFX、证书存储/EV 或 Microsoft Artifact Signing 后，主程序和 NSIS 安装器会自动使用同一发布身份签名；PFX/证书存储方式使用 SHA-256 与 RFC 3161 时间戳。
- 证书路径、密码和 Microsoft Entra 凭据只通过当前 PowerShell 会话或 CI Secret 注入，不写入源码、`.env`、数据库或发布包。
- 未签名包可能触发 Windows“未知发布者”或 SmartScreen 提示；普通 OV 新证书也可能经历信誉积累期。
