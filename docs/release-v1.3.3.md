# Card Vault v1.3.3

更新日期：2026-09-11。汇总 DeepSeek、页面改进及全项目架构整理。经用户确认，已生成 Windows x64 未签名安装包与便携包；完整源码门槛、包内运行、版本、内容与 SHA-256 验证通过，尚未上传发布。本节记录本版实际验收，不沿用旧版产物结果。

## 功能与页面

- AI 新增 DeepSeek，默认 Endpoint 为 `https://api.deepseek.com/chat/completions`、模型为 `deepseek-flash`。提供连接测试、模型列表和原生图像输入；结构化识别使用 JSON 输出并关闭 thinking。依据 [V4.1 Flash 官方公告](https://deepseek.com/news/deepseek-v4-1-flash/)及[图像输入文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)。
- 密钥沿用 Windows safeStorage 加密，旧版 v5 设置未包含 DeepSeek 时仍可读取。保存部分配置不清除其它服务的密钥；公开配置只提供密钥存在标记。
- 卡片财务历史采用稳定的日期、内容、金额和编辑列；展开修正表单时保留按钮位置，去除重复估值标题。
- 持仓财务重新排布文字和数值，统一金额对齐；首页排序简化为成本升序/降序、估值升序/降序。
- 组合栏目统一为“当前组合”“持仓”“财务趋势”“待完善数据”“售出复盘”；收藏结构去除“结构分布”，对齐集中度与 Top 1/Top 3，长产品线完整换行。
- 高成本持仓保留“均价 + 金额”；修复售出复盘日期列，缩短首页搜索提示、减少结构卡片空白。
- 中英文界面与设置中的使用说明同步更新，继续沿用现有一级入口、折叠和字重方案。

## 架构评估与整理

审查覆盖应用路由与操作、组件、领域逻辑、Electron 和维护脚本，并检查测试、配置及文档的引用关系。生产与维护源文件原计 278 个；新的架构门槛计入根级入口和新增模块，共检查 283 个源文件。

| 问题 | 本版处理 | 维护收益 |
| --- | --- | --- |
| AI 默认值、类型、公开配置和草稿合并在多个层重复 | `ai-settings-core` 统一无环境依赖的规则，Electron、服务端与 UI 复用；桌面 IPC 类型复用公共类型 | 新增服务时减少多处默认值和密钥处理规则漂移 |
| 财务表单迁移后保留旧提交入口 | 删除 6 个无调用的新增/修改操作，保留统一保存和独立删除入口 | 减少双套写入路径，继续复用校验与历史变更逻辑 |
| 分享渲染文件混合 HTML、CSS 与浏览器脚本 | 拆分 `share-gallery-styles.ts` 和 `share-gallery-runtime.ts`，保留 `share-export-render.ts` 公共入口 | 各类资产独立维护，预览与导出继续共用实现 |
| 组合类型经门面反向导入，分享问题类型由验证模块定义 | 改为直接依赖独立类型模块，移除两组类型循环 | 依赖方向清晰，减少后续加入运行时逻辑的风险 |
| 缺少架构回归门槛 | 新增 `npm run check:architecture`，纳入 `check:release` 和现有 CI | 阻止源码循环及客户端引入 Node.js/Prisma 运行时 |

架构检查使用 TypeScript AST 解析本地静态 import/export、字面量 require/dynamic import；循环检查包含类型引用，客户端边界检查先移除类型导入，并遵循 Next.js 的服务端操作边界。它不替代类型检查、构建或运行测试，也不分析动态拼接的模块路径和外部依赖包内部实现。

本轮未发现需要整体重写或引入新框架的依据。领域计算、数据库查询、桌面生命周期及 UI 已有基本分层；保留独立财务参考实现和冻结夹具，避免测试与被测逻辑共用算法而失去对照价值。大型翻译字典、样式表和业务测试不以行数为由机械拆分。密集历史和流式导出沿用 v1.3.2 的实现，本轮不宣称新增性能提升比例。

后续按实际变更热点和测量结果再拆分复杂组合查询及录入状态，先建立清晰输入/输出和回归用例；不增加平行的业务核算或导出实现。维护计划统一见[路线图](./product-roadmap.md)。

## 兼容性

数据库结构标记仍为 `1.3.0`，财务核算仍为 `physical-position-v2`，备份格式和分享内容协议不变。没有数据库迁移或真实收藏数据改写。AI 加密文件仍为 v5，DeepSeek 为可选字段；密钥按服务与自定义配置 ID 合并，未提供或 undefined 保留，明确空字符串清除。

拆分前后分享 CSS、浏览器脚本及两份生成部署说明已逐字节对照一致。既有分享预览、导出入口和内部调用保持兼容。
