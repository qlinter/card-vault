## 展示与单卡大图

### 视觉与信息层次

- 采用完整卡图、统一展位和展签，背景降低对比度。应用的经典、极简展厅、午夜典藏、暖纸档案共享现有主题变量，不改写照片颜色。
- 搜索与收藏分组置于展墙上方，卡片数量并入当前分组标题，不重复显示应用品牌、收藏大标题或“卡片主体”说明。桌面分组名采用紧凑的等宽网格，缩小芯片两侧留白及列间距，收起时只占一行，展开／收起按钮独立放在最右侧；长名称最多显示两行，窄窗口采用原生分组选择框。主体选择按英文名称在前、中文名称在后排序，中文名称内部按拼音排列；选中项只加深文字，不显示边框或底色。搜索时各分组数量按关键词匹配结果计算。搜索输入与操作文字使用同一字号。展墙与列表保留本机视图选择，搜索、分组和页码通过 URL 保留，单卡返回展墙时恢复当前页。
- 展墙默认按主体名称、录入时间和 ID 稳定排序。每页最多读取 48 张卡片，底部可翻页，顶部数量仍显示整个筛选范围的总数。桌面按可用宽度显示三至四列，平板显示两列，窄窗口显示单列。列表采用缩略图和对齐文字；桌面用公共字段表头减少重复标签，窄窗口恢复逐卡字段名，760px 及以下将名称与字段上下排布。
- 展签显示主体、卡名，以及固定列位的版本、评级、限量编号；展墙的主体名称居中，列表名称保持左对齐。缺失项显示较短的半字宽横线，同排卡片的名称、卡名、字段名与值共用行位，长文本不会把其他卡片的同类信息错开。列表沿用固定字段列。单卡详情只列出已有系列、版本、评级、卡号和限量编号；年份在标题上方出现时不再重复。空项不占位，单图不显示无意义的 1 / 1。仅展示公开描述，不把私人备注或财务信息带入展示组件。
- 主体悬停与选中通过文字深浅和字重区分，键盘保留焦点提示；禁用工具按钮不显示悬停边框。主体数量、字段名与详情辅助标签至少使用 .75rem 字号。搜索行去掉上下外留白，输入框高 36px，文字靠近底部横线；聚焦时只强调底部线条，四种主题都不叠加输入外框和发光。

### 图片与大图

- 卡图按自然尺寸与实际旋转角度计算边界，等比完整放入展位，横版与评级壳不裁切。展示留白取决于原图构图，不自动抠图、加滤镜或修改原文件。
- 展位预留固定空间，以展位底板承接加载，不在已显示的图片后方叠加加载矩形。展墙请求缓存的 640 像素 WebP 缩略图，首屏前四张提高请求优先级、前八张立即加载，其余懒加载与异步解码。图片即使先于客户端脚本完成加载，也可先显示；随后按自然尺寸精确适配，再显示贴合卡图边界的阴影。单卡详情与大图仍读取原图。缺图和解码失败提供稳定占位。
- 单卡可切换图片、临时旋转、打开大图。大图使用原生模态对话框，紧凑输入框支持在 25%–500% 之间输入任意整数缩放比例，放大后用滚动条或触控滚动查看细节。单图大图隐藏图片计数，触屏下缩放输入区域与工具按钮统一为至少 44px 高度。
- 大图方向键切图，+ / - 每次调整 50%，0 重置，Esc 关闭；输入框在回车或失焦时应用比例，超出范围时贴近边界。输入框聚焦时只强调原有边框，不叠加外框。切换图片重置缩放与临时旋转。关闭恢复触发位置的焦点，后台页面不能获得焦点或滚动。
- 图片浏览和旋转不写入数据库。上一张／下一张卡沿用当前搜索与分组，可跨页连续浏览；位于范围首尾时不提供越界入口。单卡页只查询当前位置与相邻两张卡，不读取整份卡片 ID 列表。

### 单卡图片导出

收藏页的“图片展示”标题右侧、展示单卡页的查看大图图标右侧均提供导出图标。单张下载上传原图，多张按展示顺序打包 ZIP。原始分辨率、格式与文件字节保留，不应用页面旋转，不含卡片财务或私密备注；无图片时隐藏入口，失败时保留页面并允许重试。

## 浏览展馆

展示页点击“浏览”，范围包括当前搜索和分组的全部匹配卡片，不限当前页。回顾可选择本期全部卡片或仅代表卡片，后者沿用所选顺序。关闭弹层回到原页面、筛选、分页和滚动位置。“浏览”和“分享集”采用统一的轻量工具栏样式；右侧搜索框缩至 280px，不显示占位文字，保留无障碍名称。

展馆提供四种可记忆风格：暗室聚光、白盒美术馆、暖纸典藏、月光展厅。各风格分别调整展墙、光线、地面、展签和控件配色，卡片照片保留原始色彩和完整边界。主题切换保留当前卡片、构图、画幅及灯光设置。

文字按标题、正文和辅助信息统一层级；只保留一处浏览进度，移除重复的馆藏口号和播放状态。卡名与主体相同、年份或资料已经出现在卡名中时，不重复显示；原档案内容不改写，当前售出状态仍保留。

右上角“展馆设置”用下拉列表选择展示风格、画面构图与播放模式，可切换“展馆布展／专注画面”，调节画幅大小、聚光强度、标题显隐和播放顺序。调整即时预览；点击面板底部“保存”后，在本机记住外观、播放顺序、间隔与模式，下次进入浏览时沿用。未保存的修改仅用于本次浏览，不覆盖上次保存的设置；浏览器存储不可用时会显示保存失败提示，当前预览仍可继续使用。

浏览默认使用柔和切换。每幅图片加载完成后进行约 0.8 秒的淡入和轻微舒展，缓存图片切换时也会触发；展签与控件渐显。系统开启减少动画时立即显示，不会给原图增加滤镜。键盘说明集中在“设置 → 帮助与版本 → 使用说明 → 展示”的“浏览键盘操作”中，展馆设置面板不再列出。

设置面板沿用当前展馆的配色，标题使用展签式衬线字，字段标签和功能选项遵循公共界面字体层级。下拉框和秒数输入采用透明底、细底线，字号与常规输入统一为 14px，控件高度统一为 40px；滑杆和勾选框使用主题强调色。支持可定制原生下拉菜单的环境还会显示主题菜单与四种风格色样；其他环境保留原生选择方式，键盘操作和保存行为一致。按 Esc 时，先关闭已展开的下拉菜单，再依次关闭设置、退出全屏和返回原页面。

控件闲置后只淡出，不改变画幅位置或大小；移动鼠标、触屏或键盘操作恢复显示。关闭设置会恢复焦点。

- 从展示页开始时，顺序播放沿用展墙的主体、录入时间和 ID 排序；代表卡片沿用策展顺序。随机每轮不重复，上一张沿实际浏览记录返回。
- 默认暂停、8 秒间隔，可自定义为 1–3600 秒的整数。空值离开输入框时恢复有效值，超出范围会调整至边界，小数四舍五入。图片加载完成后开始计时，加载失败不会持续自动跳转。
- 播放模式默认“首图”，播放每张卡的第一幅图片；“全部”逐张播放每张卡的全部图片，沿用档案图片顺序，不推断正反面。间隔按每幅图片计算，点击“保存”后可在下次浏览沿用。
- 显示标题、卡片主体和当前售出状态，可隐藏标题；不显示财务或私人备注。
- 图片完整适配，支持 25%–500% 缩放和临时旋转，不写入图片或档案。
- 全屏需手动进入，仅展馆内容进入全屏，底层项目页面不参与显示；退出后恢复窗口模式。
- 失焦或页面隐藏即暂停，回到窗口后手动继续。手动切图、缩放、旋转及设置操作也会暂停。
- 缺失图片可重试或跳过；全部不可用时停止播放并提供退出。播放中删除的卡片可跳过。

| 按键 | 操作 |
| --- | --- |
| ← / → | 上一张 / 下一张卡片 |
| ↑ / ↓ | 上一幅 / 下一幅图片 |
| 空格 | 播放 / 暂停 |
| + / − / 0 | 放大 / 缩小 / 重置 |
| Esc | 先关闭设置，再退出全屏，最后退出赏卡 |

会话 ID 按批加载，单次最多 500 个；加载清单期间资料版本发生变化时停止并提示重试，避免缺漏。图片只加载当前图和下一张卡的第一幅预载，切换或退出取消过期请求。长会话的 ID 与实际浏览历史保留在窗口内存，退出后释放，不预载全部原图。

## 收藏回顾

从统计页右上角的“收藏回顾”进入，沿用当前筛选范围；也可切换全部收藏。选择年份、全年或月份，再选择口径：

- **购入回顾**：只使用购入交易记录中的日期与数量。重复购入累计数量，涉及档案单独去重。没有购入记录的档案不猜测日期，并显示范围内缺失数量。
- **录入回顾**：按档案创建时间计算新增档案。例如在 2026 年补录 2020 年购入卡片，它进入 2026 录入回顾；记录了 2020 购入交易才进入 2020 购入回顾。

这里的“档案”就是一条收藏记录，与图片数量、交易次数或实物张数无关。例如同一档案在期间内先购入 2 张、后购入 3 张，会计为购入 5 张、涉及 1 个档案；分别建成两条记录则计为 2 个档案。录入口径按新建记录计数，主体、运动和系列榜单也按涉及档案计数。

期间按 UTC 日历边界计算，与财务录入的日期保存方式一致；未来日期不计入，当前期间的导出图标注“截至当前”。卡片年份筛选与回顾年份独立。签名、评级、主体及系列采用当前资料，不能解读成历史评级事件。已售出卡片仍属于其购入期间；主动筛选“持有中”时则只回顾该范围。

年份、月份或回顾口径变化后自动切换数据，不需要保存或提交。页面直接替换数据，不使用淡入、位移或变淡过渡；请求期间保留原画面并暂时锁定旧内容操作。年份输入有效后短暂等待再切换，避免输入过程触发错误期间；筛选范围与期间保留在地址中。年度活动图按月展示，点击月份进入月度；月度图按周一至周日分组，首尾周只包含本月日期。

标题默认为“2026年1月收藏回顾”，全年为“2026年收藏回顾”。标题及代表卡片可临时调整以供当前浏览和导出；更换期间或重新载入会根据当前数据重新生成。回顾不再提供保存、历史列表或历史编辑接口。

代表卡片初选最多六张，优先覆盖不同主体，再兼顾月份，不按价格、稀有度或评级排序。“卡片调整”展开候选列表，可移除、替换及排序。标题旁的“包含私密卡片”采用紧凑开关，默认关闭；“生成长图”直接下载 PNG。导出按隐私选择重新计算数据，不含财务和卡片私人备注。

上述临时调整不会写入数据库，也不触发历史数据清理。

<a id="wishlist"></a>
## 目标与寻卡

### 跨站查询

输入关键词，点击卡淘、eBay 或 130point 打开外部网站，也可复制关键词。卡淘与 eBay 使用当前输入构造查询地址；130point 打开其查询页面后自行粘贴。外链在新窗口打开。

查询不保存关键词或查询历史，不关联心愿或卡片。卡片详情仍可将卡片信息带入查询框，这只是填写搜索文本，不建立关系。

### 心愿单

名称为唯一必填项；主体、预算及币种、备注为可选。可新增、编辑、删除，按名称、主体和备注搜索，每页 20 条。默认按新增时间倒序排列。

预算为原币金额，区分未填写与零，最多两位小数，不影响卡片成本、估值或财务流水。保存失败保留输入；保存成功但刷新失败时只需刷新列表，不重复提交。心愿草稿按收藏库保存在本机，关闭编辑或刷新后可继续。

不再提供关键词管理、关键词关联、优先级、目标日期、目标数量、入藏、卡片绑定、进度、状态归档或独立清单导出。

图片浏览、临时旋转与回顾选卡不修改原图或收藏记录。数据格式、备份与停用历史的处理只在[数据管理](./data-guide.md#backup)维护；跨主题字级、颜色和控件约束见[设计规范](./design-system.md)。
