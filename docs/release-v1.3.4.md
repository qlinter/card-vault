# Card Vault v1.3.4

更新日期：2026-09-18。经用户确认，已生成 Windows x64 未签名安装包与便携包，完整源码门槛、包内运行和产物校验全部通过。

## 更新内容

- 录入页采用紧凑、自适应字段布局，统一输入框、标签和按钮的对齐；展示描述与备注并排，减少重复留白。
- 上方字段分为“卡片信息”“评级信息”，沿用“财务记录”的标题栏样式；评级信息包含评级机构、评级、证书号和评级链接。财务记录及以下区域保持原有布局。
- 签字类型与 Patch 类型移至属性选项上方，填写后自动勾选对应属性；清空类型后可手动取消。AI 填入、草稿恢复及保存校验采用同一规则。
- 限量编号、签名、Patch/Jersey、Rookie 在评级区域上方同排，对齐四列；填写编号或编号范围会即时勾选限量选项。
- “初始财务记录”改为“财务记录”，保留原有快捷字段，增加“新增记录”入口，可补充交易、费用和估值，包含混合币种付款与出售关联费用。卡片和记录在同一事务中提交，任何失败都会回滚；补充记录随草稿保存与恢复。
- 原有详情页财务录入与核算规则保留。补充记录是额外记录，已经在快捷字段填写的同一笔交易无需再次添加。
- 首页简化为“卡片”“估值”，移除估值栏中的“组合”链接，保留“组合分析”。眼睛图标切换估值显示，记忆本机选择，隐藏状态下重载不闪现金额。
- 首页排序框默认显示“排序”，保留“最新录入”名称和默认规则。
- 移除“保存并复制新增”及其逻辑，精简录入说明并集中到设置的使用说明。
- 新建分享移除说明性副标题；数据导出的 CSV/XLSX 与前方控件对齐，列表/表格切换沿用首页紧凑样式，去除“导出搜索结果”说明文字。
- 中英文 README、路线图、文档索引及应用内更新说明同步至 v1.3.4。
- 组合“待完善数据”去除无问题时的说明文字；心愿单移除“取消心愿”和“取消编辑”，编辑区域增加“删除心愿”，确认后删除并同步刷新列表与预算。历史已取消的心愿继续保留。
- 心愿列表的主体、预算金额与“编辑／已实现”操作共用一行并居中对齐；标题、日期、状态和备注独立排布，长标题换行不再影响按钮与金额对齐。

## 结构整理与复核

- 初始购买、评级费用、估值和补充记录统一由 `card-entry-finance-service` 编排，录入与导入共用；数据导入不再依赖包含图片处理的完整录入服务。保留已有事务、财务核算和详情页流程。
- 录入页和详情页共用费用类型选择器，使用现有财务标签表；移除未使用的说明分支、可选参数和内部导出，合并重复的录入及心愿样式覆盖。
- 更换 AI 识别图片时先清空文字，再清空编号、签名与 Patch 属性，避免旧类型字段重新触发勾选；补充草稿重载回归。
- 财务载荷拒绝数组形式的字段容器，对无效 JSON 返回明确错误；架构检查同时禁止客户端引入 `server-only` 模块。
- 中英文 README、路线图、文档索引、使用说明与“关于”同步。路线图移除重复历史发布细节，改为链接各版记录；保留全部历史版本、独立财务对照基线、当前备份保护和既有分发文件。
- 现行备份、分享和临时发布规范统一标注 v1.3.4；修正历史版本总数为 28，并核实本地 v1.3.0 标签已存在。文档门槛新增历史计数与规范适用版本校验；签名指南不再复述旧包验收，命令从项目元数据读取版本。

## 数据与分发边界

数据库结构、财务历史表及备份格式未改变。旧草稿继续可读；新增财务记录随现有草稿 JSON 保存。未改动已有收藏；v1.3.3 安装包、便携包及校验清单已原样归档至 `backups/releases/v1.3.3`，归档副本的哈希与原文件一致。
