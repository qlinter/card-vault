## v1.4.0 已完成

首页估值、卡片和收藏概览三模块并列并跟随筛选；寻卡包含跨站查询、统一的已保存关键词管理、心愿单与入藏联动。关键词仅保留查询、保存、复用、删除与关联心愿；商品、价格及研究记录模型和接口已删除。心愿目标进度、多卡绑定、搜索排序、草稿恢复、反向关联与 CSV 清单导出已完成。导航、异常恢复、聚合拆分和共享导出清理纳入本版。

后续版本按需求逐步加入卡淘自动更新、到价提示及更多来源；本版无后台采集。

## v1.4.1 已完成

v1.4.1 已实现 Next.js / Electron 安全依赖升级、寻卡异常滚动缓存恢复、搜索防抖、数据库分页和工作区关联索引复用；数据板块按总览、趋势、结构、明细四页签整理，增加实物数量、范围保留、完整问题明细、趋势交互及固定快照与历史比较，详见[数据分析规则](./data-analysis-guide.md)。回归保留财务独立对照，复用现有数据结构。本版源码版本、规范和发布说明已同步；新分发包单独生成。

## v1.4.2

展示采用完整卡图展墙、紧凑列表、展签与大图观赏；此前评估后的录入、导入、数据复用、备份和可靠性改进统一归入本版。具体状态与验证范围见[开发记录](./development-v1.4.2.md)。本轮不生成分发包，财务编辑留痕与误操作恢复已排除。

## v1.5.0 分阶段轻量化

第一阶段实施收藏首页、录入首屏、单卡详情和两步分享，保留 AI 组合分析。第二阶段已实施导航归并、整理清单合并及导出复用；第三阶段 3A 已实施独立跨站查询和简化心愿录入，移除关键词管理、入藏及卡片绑定；按用户新增授权一次性清理旧寻卡与心愿记录。3B 已移除重复搜索、快照及比较，并一次性清理分析历史；保留两张趋势图的独立时间范围。3C 已完成四项设置主列表、底部帮助与版本、数据分组及 AI 配置集中展示；心愿单置于跨站查询上方。不增删数据库表或字段，其他卡片、财务与分享数据以及备份、导入导出兼容性保留。

本版收尾进一步修复保存与草稿恢复，清理失效组件与样式，分离数据导航、聚合及说明内容，共用历史清理安全流程与运行脚本白名单。当前 Windows 分发及 GitHub 同步记录统一维护在发布说明，后续工作仍以实际使用反馈为依据。

## 后续优先级

| 优先级 | 方向 | 启动与验收条件 |
| --- | --- | --- |
| 1 | 大数据与故障恢复持续验证 | 已实现组合分批聚合与分阶段计时，完成真实大照片、磁盘不足及三个进程退出边界验证；继续根据实测定位查询与渲染瓶颈，物理断电验证需独立环境。 |
| 2 | 使用反馈驱动的体验改进 | 记录录入、查找和整理的实际困难；维持现有布局与字重方案，按反馈调整，不无依据再做整页改版。 |
| 3 | 数据规则扩展 | 在已有精确状态开始日期基础上扩展完整状态变更历史、更多导入字段及更细纠错流程，先明确模型与兼容要求。 |
| 暂缓 | 长期在线发布与多设备同步 | 用户重新确认需求，并具备长期托管、身份、运维与恢复条件后再规划。 |

已取消的独立批量修改入口、最近批次列表、系统摘要通知和分享“更多”菜单不再作为待开发事项。没有独立手机版本计划；分享网页仍需适配手机浏览器。

## 持续规则

财务改动复用[统一核算](./financial-history-model.md)，缺失值不能当零；数据库与媒体变更须具备快照、回滚或冲突保护。保留用户原文、表单输入、筛选和返回上下文。测试使用隔离数据；统计覆盖率仅代表实际加载模块。后续版本号在范围确认及发布收口时确定，中英文路线图同步维护。
