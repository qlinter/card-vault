# v1.7.2 版本说明

2026-11-27 · Windows x64

- **收藏与录入**　单卡新增履历，录入工具的标题、计数和展开箭头对齐。图片与资料等高，展馆图状态及公开状态直接显示。队列草稿可恢复图片与旋转，多窗口修改和删除会核对版本。[操作说明](./collection-guide.md#archive)
- **财务与统计**　支持获赠、赠送和未知成本，赠送按零收入并入已实现盈亏。同日交易先入后出，限制未来交易和导致库存失去依据的删除。明细可按最近活动排序。[财务模型](./financial-history-model.md)
- **收藏回顾**　取得、转出按交易日期统计，建档按当地日期统计，页面和导出长图共用同一口径。[收藏回顾](./collection-guide.md#recap)
- **导出合影**　四种构图共用「较准页面」，已保存的卡面框可以重新调整。展台支持 AI 精修。[合影操作](./collection-guide.md#group-photo)
- **单卡制图与 AI 设置**　重新生成时使用当前首图，保留本卡评级或使用标准透明磁吸卡砖。样图提供布景和卡架，提示词不写人物姓名。「待生成」旁可直接补图。三个 AI 设置区各自保存。单卡可上传本地展馆图，预览后采用。审核失败时可查看服务返回的阶段和类别。[制图设置](./data-guide.md#studio-ai)
- **维护**　分享集编辑预览与导出共用公开卡牌字段，财务新增与编辑共用校验。登录页在交互就绪后启用登录和找回密码操作。桌面端会检查启动所需的构建文件，开发构建中断后可重新准备。开发缓存、界面测试的模拟收藏库和报告可按需清理。[开发维护](./development.md)

## 本次同版本源码整理

- 录入模板和批量队列共用标题、数量和展开箭头，紧凑按钮共用尺寸。模板的新建和更新复用同一保存流程。删除模板、队列条目和心愿时使用统一的删除按钮。
- 单卡编辑页通过图片展示展馆图状态。选择「保留原图」继续使用当前展馆图，选择「采用新图」后按新成品版本刷新缩略图。AI 设置各区的操作靠左排列，「保存设置」紧跟本区其他按钮。
- 本次更新沿用 v1.7.2。核对 Windows 下载文件时，以同一发布页的 `SHA256SUMS.txt` 为准；构建清单 `release-1.7.2.json` 记录对应源码提交。[Windows 下载](https://github.com/qlinter/card-vault/releases/tag/v1.7.2)
