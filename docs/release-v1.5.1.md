# v1.5.1 发布说明

日期：2026-11-02；源码整理、Windows 分发与验收：2026-11-03。当前版本为 v1.5.1。Windows x64 安装包和便携包均已生成并通过完整流程，下载入口为 [GitHub v1.5.1](https://github.com/qlinter/card-vault/releases/tag/v1.5.1)。

## 功能与界面

- 内置 AI 服务为 OpenAI、MiniMax、DeepSeek。OpenAI 默认 `https://api.openai.com/v1/chat/completions` 和 `gpt-5.4-mini`，可修改模型或读取模型列表；已有 Azure 配置迁为自定义服务，保留原地址、部署与认证，密钥不会复制给 OpenAI。
- 收藏与展示的单卡页提供图片导出图标：单张下载原文件，多张按展示顺序打包 ZIP；页面旋转不改写原图，不附带财务或备注。展示页入口在查看大图图标右侧。
- 主导航“数据”更名为“统计”，收藏页入口为“目标 & 寻卡”。设置各模块操作按钮统一为灰色；“网络与代理”标题不附带当前模式，说明集中到[代理指南](./ai-proxy-guide.md)。

## 保存与凭据可靠性

- 同一次录入、草稿或队列的重复及并发提交只生成一份卡片、图片和初始财务记录；独立录入仍可收藏同款卡。草稿同步失败保留输入并停止入库。
- 卡片档案、图片与收藏状态保存校验来源版本。交易、费用、估值的修改和删除也检查完整内容版本，兼容 SQLite 文本日期与 Prisma 日期；冲突不覆盖最新数据，保存失败保留输入。
- 分享编辑校验基本资料、条目、章节及媒体引用；冲突保留输入和本页选择的文件，失败请求清理自身暂存上传。草稿保留来源版本，恢复旧草稿不能覆盖新内容；未保存文件不能通过草稿跨页面恢复。
- API Key 与代理密码暂时无法解密时，保存其他设置保留原密文并继续提示；只有明确替换或清除才修改对应凭据。凭据保存在设备安全存储中，不随收藏备份迁移。

## AI 网络与代理

支持设备本机保存的自动、直连和手动 HTTP/HTTPS/SOCKS5 代理、认证及绕过规则。自动模式按服务地址读取环境变量和桌面系统/PAC 规则；不按模型名猜测线路，不进行后台网络探测。

支持 IPv4/IPv6 网段绕过、系统有序候选和系统明确的 DIRECT；每次重定向重新分流，跨域去除私有 Header，拒绝 HTTPS 降级并保留证书校验。主动连接测试显示脱敏线路结果，区分地址解析、连接、认证和证书错误；文本测试不代表图片识别能力或准确率。

读取模型、连接测试、识图、组合分析和分享文案的请求按各自生命周期传递取消。离开分享编辑页会取消在途文案生成及格式修复。模型或认证设置变化后取消旧设置请求；选择模型仍保留已读取的模型列表。

## 结构与文档整理

- AI 内置服务共用表单与凭据处理；连接测试和模型列表共用请求生命周期管理。
- 分享封面、背景使用统一媒体服务；文案字段与类型为前后端共享定义，API 路由仅保留请求与错误处理，生成和格式修复集中在服务模块。
- 移除未使用的格式化代码、财务内部参数和过时的模型字段间接配置，收窄仅在模块内部使用的导出。
- 发布验收纳入真实 Electron PAC 引擎的本机测试；Windows 发布工作流收集 `release-*.json` 构建清单。
- 本文件维护当前版本变更；具体审查与验证记录集中到[2026-11-03 审查](./assessment-2026-11-03.md)，使用及数据规则保留在各功能规范，旧版本发布记录保留。

数据库表、字段及备份、CSV/XLSX 格式保持兼容。本次没有新增业务功能或执行收藏数据清理。
