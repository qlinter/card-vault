# 数据分析板块

v1.4.1 的“数据”板块使用“总览／趋势／结构／明细”四页签和统一范围工具栏。页面沿用现行财务模型，业务计算见[财务规则](./financial-history-model.md)；本版发布与验收见[发布说明](./release-v1.4.1.md)，分阶段记录见[开发记录](./development-v1.4.1.md)。

## 范围与数量

四页签共享已应用的收藏筛选。顶部逐项显示条件，可移除单项或清空；“调整范围”仅提供搜索关键词，点击“搜索”应用，保留继承的运动类型、品牌、收藏状态等其他条件。明细搜索、问题分类及结构下钻是当前范围内的进一步筛选；不会扩大到其他收藏。卡片使用 ID 精确打开，返回地址保留页签、搜索、排序、页码和关联维度。

档案数按条目计算，实物数按当前剩余数量计算。已售档案保留在档案总数和历史交易中，当前实物数量为零。一项档案持有多张时，成本和估值使用实物数量，覆盖率继续使用持仓档案作为分母。

## 四页签

| 页签 | 内容 |
| --- | --- |
| 总览 | 持仓估值、剩余成本、未实现及已实现盈亏；数量与覆盖率；可展开财务依据、高价值持仓和问题入口。 |
| 趋势 | 月度财务与买卖活动；6／12／24个月或全部；图例开关、原始月度表、金额与数量切换、持仓估值总额变化。 |
| 结构 | “结构分布／卡片属性”并排切换；展示全部档案数量、当前实物数量、持仓估值与估值占比；前五项及列表末尾展开、范围内下钻和已售归档入口。 |
| 明细 | 持仓、出售、待完善和全部；搜索排序、每页20项；问题分类与卡片详情跳转。 |

估值总额只汇总有报价的持仓，覆盖不足时标明部分；无报价不视为零。完整成本或收益缺少依据时保留空值并提供问题入口。零、缺失值使用中性色。持仓估值变化包含交易数量和报价的变化，不是同卡价格收益率；任一时点没有报价基准时不显示比较金额及涨幅。

财务趋势和活动趋势各自选择6／12／24个月或所有，分别随页面地址保留，切换页签、搜索及保存快照不相互覆盖。所有范围从各自首笔相关记录所在月份开始，并连续显示到当前月；当前月为截至当前的数据。金额缺失保持断点，数据表按同一数据源展示。活动趋势以“金额／数量”切换，金额包含买入、出售与费用；数量仅包含按实物张数统计的买入与出售，图例、提示和数据表均不显示费用。

结构页不再切换档案、实物或估值统计口径：档案数量统一包含当前范围内的全部档案（含已售），实物数量和估值只统计当前持仓。“估值占比”及分布条统一以当前范围已估值持仓总额为分母，未估值保持空值；属性可重叠，占比不应相加。分布按估值排列，默认显示前五项，在列表末尾通过文字折叠项查看其余记录，展开后的“收起”也位于完整列表末尾。页面移除统计说明行及HHI，仅保留Top 1、Top 3、Top 5估值占比，同一行展示。集中度是范围内的描述指标，不将用户主动选择的收藏方向直接判为风险。

已出售且持仓为零的档案，在对应结构和属性的档案数量下标记“已售 X 项”，标记使用正文同等字号，主数量与各金额、占比按同一行对齐；点击标记可打开同一范围、同一分类的已售归档清单。部分出售但仍有持仓的档案不计入已售归档，剩余数量和估值仍属于当前持仓。清除明细筛选或切换明细分类可退出已售归档筛选。

## 快照、比较与问题处理

顶部“快照与比较”仅保留固定快照，支持保存、查看、重命名和删除。快照冻结当时的范围、统计及核算依据，单独查看或重命名均不会重算内容、修改捕获日期。动态视图的保存、更新和比较入口已移除；旧版本视图表保留在数据库及备份中，不参与当前查询，已有快照不受影响。

比较提交后自动展开，注明实时范围比较或包含冻结时间点；两侧显示范围、日期、金额及核算依据，结构差额使用百分点。管理操作保留当前页签和范围。

比较控件先选择对象、后选择基准，隐藏两者的可见标签并保留可访问名称。基准A仅选择历史快照，对象B选择当前数据或另一份历史快照，差额按B−A计算。默认A为最近保存的快照，B为当前数据；没有快照时先保存，再使用比较功能。当前数据始终按最新记录与汇率依据计算，历史快照保持冻结。财务明细不再列出“本次使用的汇率”，核算与快照仍保留完整汇率依据；比较继续拒绝不一致的核算版本或报表币种。

待完善分为影响核算（成本、汇率、报价、交易及估值时效）和档案整理（图片、基础资料）。每类提供完整分页清单；当前估值超过180天提醒更新，已售卡不要求当前报价。既有首页的完成、忽略、延后等整理流程继续在首页处理，数据板块用于定位事实缺失。

## 加载与验证

当前页签加载所需数据；只有趋势页重建完整月度历史。总览、结构和明细复用统一分批核算，在同一遍计算中收集轻量的数量与明细，仅明细页保留列表以便搜索排序及分页；其余页签只保留汇总与前五项持仓，不再排序整套明细。比较复用当前结果，旧快照读取冻结内容。工具栏先显示，内容与比较分别提供失败重试。

财务冻结对照实现继续留在 `tests/fixtures/*-reference.ts`，本次展示收集不得改变核算结果。补充测试覆盖重复卡名的精确ID、档案与实物数量、缺失成本与报价、分页、范围保留、汇总与明细等价性及特殊文本分组；界面覆盖中英文、最小桌面窗口、主题、趋势交互、快照不可变性与损坏上下文写入保护。
