# v1.7.2 版本说明

2026-11-27 · Windows x64

- **收藏与录入**　单卡新增履历，图片与资料等高，展馆图状态及公开状态直接显示。队列草稿可恢复图片与旋转，多窗口修改和删除会核对版本。[操作说明](./collection-guide.md#archive)
- **财务与统计**　支持获赠、赠送和未知成本，赠送按零收入并入已实现盈亏。同日交易先入后出，限制未来交易和导致库存失去依据的删除。明细可按最近活动排序。[财务模型](./financial-history-model.md)
- **收藏回顾**　取得、转出按交易日期统计，建档按当地日期统计，页面和导出长图共用同一口径。[收藏回顾](./collection-guide.md#recap)
- **导出合影**　四种构图共用「较准页面」，已保存的卡面框可以重新调整。展台支持 AI 精修。[合影操作](./collection-guide.md#group-photo)
- **单卡制图与 AI 设置**　重新生成时使用当前首图，保留本卡评级或使用标准透明磁吸卡砖。样图提供布景和卡架，提示词不写人物姓名。「待生成」旁可直接补图。三个 AI 设置区各自保存。[制图设置](./data-guide.md#studio-ai)
- **维护**　分享集编辑预览与导出共用公开卡牌字段，财务新增与编辑共用校验。登录页在交互就绪后启用登录和找回密码操作。桌面端会检查启动所需的构建文件，开发构建中断后可重新准备。开发缓存、界面测试的模拟收藏库和报告可按需清理。[开发维护](./development.md)

Windows 本机生产构建通过。446 项单元测试、296 项浏览器回归，以及卡牌、分享、数据管理、寻卡、导出、展示六组端到端流程全部通过。中英文 Electron 实测验证了 AI 设置分区保存和重启读回。制图回归使用测试卡与模拟服务。
