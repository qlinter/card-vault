# v1.4.1 Git 更新说明

版本：1.4.1；日期：2026-10-23。功能、核算边界与验收见[v1.4.1 发布说明](./release-v1.4.1.md)。

## 提交内容

提交标题：

```text
feat: release v1.4.1 Data workspace and desktop improvements
```

- 新增数据总览、趋势、结构、明细四页签，共享范围、独立趋势期限、已售结构下钻和固定快照历史比较。
- 优化首页概览、整行点击、视图切换、筛选入口及文字对齐；保留已有内容直到导航就绪。
- 优化寻卡搜索、防抖、分页、关联索引和异常缓存恢复；修复桌面启动器运行程序准备及重试。
- 统一页面参数和寻卡序列化，汇总页保留前五项而非整套明细，修复特殊文本分组计数，快照上下文在写入前校验；删除旧布局、动态视图操作、失效样式与重复发布入口。
- 同步版本元数据、应用内双语更新、README、规范、路线图、发布说明、测试及截图基线。

## GitHub 同步

使用现有`master`分支提交，创建注释标签`v1.4.1`并推送到`origin`；推送前核对远程分支，使用正常快进更新，不改写历史或覆盖既有标签。GitHub版本说明与该标签指向同一份源码。

```powershell
git push --atomic origin master v1.4.1
```

GitHub `Quality`工作流会对`master`提交运行完整质量门槛。Windows产物由`.github/workflows/release-windows.yml`单独手动生成，不因源码标签自动打包。GitHub版本本轮仅提供源码，未附安装器或便携包。

## 提交与数据边界

包含本版代码、依赖锁文件、测试、截图基线和文档，以及旧模块和重复工作流的删除。`node_modules`、`.next`、`dist`、日志、测试运行目录、个人数据库、媒体、备份和桌面配置继续排除在提交之外。

数据库结构及财务核算版本不随产品版本改变。四份财务独立参考实现保留原样；既有收藏和历史发布文件不作为冗余内容删除。验收以本版发布说明中的实际结果为准，Git同步源码不能替代个人收藏备份。
