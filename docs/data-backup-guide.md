# Card Vault 数据备份说明

适用版本：`1.2.0` 当前数据库基线。

## 1. 数据保存位置

Card Vault 的收藏数据由以下内容共同组成：

- `dev.db`：卡片、财务历史、录入草稿、模板、批量队列、分享集、收藏视图和时间点快照数据。
- `uploads`：卡片图片与已经完成预处理的队列 WebP。
- `thumbnails`：首页使用的可重建 WebP 缩略图缓存，不属于必须备份的收藏原始数据。
- `entry-queue`：批量录入队列中尚待处理或可重试的源图片。
- `share-covers`：分享集自定义封面。
- `share-backgrounds`：分享集自定义背景。

桌面端默认数据目录通常是：

```text
C:\Users\<你的用户名>\AppData\Roaming\Card Vault\data
```

如果在设置页修改过“存储路径”，请以设置页显示的路径为准。

## 2. 推荐备份方式

设置页“一键备份”会复制全部原始媒体资源，使用 SQLite 一致性快照保存正在使用的 `dev.db`，并检查数据库完整性。可由原图重建的 `thumbnails` 缓存不会进入备份。该方式无需退出程序，也是日常备份与换机前备份的首选。

手动备份时，请先完全退出 Card Vault，再复制整个数据目录。不要只复制数据库或只复制图片；否则会得到不完整的收藏数据。压缩整个数据目录为 ZIP 适合长期归档和跨电脑传输。

一键备份会按日期创建目录；同一天多次备份会生成独立 data 子目录，不覆盖已有备份。

## 3. 从备份恢复

1. 打开设置页的“备份与恢复”。
2. 点击“备份恢复”。
3. 选择一键备份生成的日期文件夹，或直接选择其中包含 `dev.db` 的 data 文件夹；日期文件夹中存在多次备份时，程序会使用最新的一份。
4. 确认恢复。程序会先备份当前数据，再将来源复制到暂存目录。
5. 暂存数据完成必要的 v1.1.0 → v1.1.1 财务升级及 v1.1.1 → v1.2.0 结构升级，并通过 SQLite 完整性检查和当前 `1.2.0` 数据库基线校验后，才会替换当前数据目录。
6. 恢复成功后本地数据服务会在应用内重新连接，当前页面自动刷新并加载备份数据；Electron 应用不会退出或重启。

恢复中途失败时，当前数据目录不会被替换；已经进入切换阶段后发生失败，也会使用保留目录回滚。

## 4. 当前数据库基线边界

- 新建数据库会直接创建完整的 `1.2.0` 当前结构；已有 v1.2.0 数据只做当前结构与完整性校验，不会重复改写数据。
- v1.1.1 数据升级到 v1.2.0 时，会先创建 SQLite 一致性快照，再一次性增加收藏视图、时间点快照和图片旋转元数据；卡片、图片文件及既有业务记录不会被转换。
- 恢复 v1.1.1 备份时，会在暂存区执行同一套 v1.2.0 结构升级；恢复已升级的 v1.2.0 备份不会重复执行。
- 恢复 v1.1.0 备份时，会先执行持仓与费用归属升级，再补齐 v1.2.0 结构。更早版本的原始 `dev.db` 不会自动升级，必须先由保留对应迁移能力的旧版 Card Vault 完成升级，再使用当前版本重新备份。
- 旧迁移记录表即使仍存在于已经升级的用户数据库中，也不会被读取、写入或删除，不影响当前功能。
- 应用不会替换或转换历史卡片原图。普通单卡上传继续保留原格式，批量录入队列的新图片仍按既定规则预处理为 WebP；首页会为首图另行生成最长边 640px 的 WebP 缩略图缓存。

## 5. 更换存储路径

- 更换路径会由独立存储进程把完整数据复制到暂存目录，`dev.db` 使用 SQLite 一致性快照，校验通过后才切换路径并重启应用。
- 新目标必须是空文件夹或可识别的 Card Vault 数据目录；程序不会覆盖无关的非空目录。
- 选择已有 Card Vault 数据的目录时，程序会先检查数据库完整性；失败时保留原存储配置并恢复本地服务。
- 存储路径移动与数据库版本升级是两件事。移动路径不会改变卡片内容或数据库结构。

## 6. 数据健康与清理

- “检查数据健康”会检查 SQLite 完整性、数据库引用但本地缺失的媒体，以及本地存在但未被引用的媒体。
- 健康检查本身只读取数据；未引用文件可在资源管理器中定位。
- “清理未引用文件”会二次确认并重新检查，只删除仍未被引用且位于受管媒体目录中的文件。删除无法撤销，建议先执行一键备份。
- `entry-queue` 源图、队列 WebP、分享封面和分享背景都在备份、恢复、健康检查及清理边界内。

## 7. 换机检查清单

- 在旧电脑设置页执行一次“一键备份”。
- 确认备份目录同时包含 `dev.db` 和相关媒体目录。
- 在新电脑安装同一当前版本后，通过“备份恢复”导入。
- 恢复完成并自动刷新后，检查卡片数量、图片、财务历史、草稿、模板、批量队列、分享背景、收藏视图及时间点快照。
- 确认无误前，不要删除旧电脑或外部存储上的最后一份完整备份。
