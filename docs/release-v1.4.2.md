# Card Vault v1.4.2 更新说明

版本日期：2026-10-24。源码版本：`1.4.2`。此前在 v1.4.1 评估后完成的修改，按用户确认统一归入本版。

## 展示视觉升级

- 完整卡图展墙、稳定展位、清晰展签和紧凑列表；搜索、主体分组与视图切换降低视觉权重，背景衬托卡片。
- 主体选择收起时压缩为单行，并缩小左右留白和列间距；英文主体排在中文主体之前，选中项只加深文字，不显示外框。展墙的主体名称居中，缺失字段使用更短的横线。
- 展墙每页读取最多 48 张卡，保留筛选总数和当前页；单卡可跨页浏览相邻卡片，返回时恢复原页。
- 横竖版、评级壳和旋转后的图片按真实边界等比适配；保留图像颜色与内容，统一缺图、解码失败和空收藏状态。
- 展墙使用缓存的轻量缩略图，首屏图片优先加载并能在页面脚本接管前显示；单卡和大图仍使用原图。
- 首屏移除叠加的加载矩形，阴影在卡图完成尺寸适配后显示；统一搜索聚焦、主体悬停和禁用按钮状态，辅助标签字号略增大，760px 以下的列表名称与字段上下排布。
- 单卡大图与收藏信息采用双栏布局；支持多图、临时旋转、25%–500% 任意整数比例输入、滚动和键盘操作。缩放输入框进一步收窄，聚焦时不叠加外框，底部只保留输入框及加减控制。
- 单图大图隐藏冗余计数，触屏下缩放输入区域增高至与工具按钮一致。
- 四种应用主题、中英文、长文本、窄窗口及减少动画设置统一适配。规则见[收藏展示规范](./showcase-guide.md)。

## 评估后的改进

- 统一前端、请求代理与服务端图片限额；按张处理媒体，草稿保留图片和旋转，消费草稿及删除时清理临时文件。
- 录入常用字段与低频字段分组，已有内容、AI 回填及校验错误自动展开；提供年份、品牌和系列建议。识别与组合分析可取消，并阻止延迟结果回填。
- 修正首页估值覆盖率、结构下钻范围及历史快照可比性；损坏快照不阻断其他页签，仍可删除。
- 导入预演每轮批量匹配不超过 100 个不同条件，执行按最多 50 行返回增量状态；继续保留逐行事务、冲突指纹与现有导入撤销。
- 数据页按收藏库、范围和修订号复用核算及轻量投影，时间边界、未来记录、汇率及卡片变化触发失效；相同筛选排序可跨页复用。初次核算仍需要读取范围内记录。
- 备份及恢复增加可用空间预检、最近成功备份状态；空闲自动备份默认关闭，启用后按现有独占操作流程执行，同库自动备份才参与保留策略。
- 拆分主要表单和导入组件，集中指标、筛选、批次类型及操作错误；仅打包命令与默认完整发布流程分离，并记录来源清单。

## 范围与验证

数据库结构与财务核算版本保持现行格式。财务记录修改留痕与误操作恢复按用户要求排除；现有导入撤销继续保留。

此前阶段的针对性验证及本轮展示验证统一记录在[开发记录](./development-v1.4.2.md)。用户要求跳过完整质量门槛，本版不将历史完整检查结果表述为新一轮验收。

本轮展示开发完成：10 项相关单元测试、2 项正常截图比较、隔离浏览器流程、类型与改动文件 Lint、生产构建、架构及文档元数据检查通过。视觉复核使用测试卡图，覆盖三种桌面宽度、四种主题、多图与异常状态；分页另以 101 张隔离测试卡验证三页、跨页导航及搜索范围。
