# Card Vault 项目审查与 v1.5.1 验收

日期：2026-11-03；版本：v1.5.1。范围包括当前工作区尚未提交的改动。本文件集中维护本日审查、整改与验收结果，版本变更概览见[发布说明](./release-v1.5.1.md)。

## 范围与结论

审查覆盖卡片录入与草稿、财务与统计、分享及媒体、导入导出、备份恢复、AI 与代理、Electron 本地会话、构建与发布工具、测试和文档。项目继续采用本地优先的现有架构，无需整体重写。此前提出的功能扩展暂缓，不纳入本轮开发。

保留既有未提交工作，不读取个人密钥、不调用外部 AI、不修改个人收藏、不提交或推送源码。本次执行完整源码发布验收；安装包构建与对外发布不作为完成项。

## 已解决的可靠性问题

本日初次评估在临时 SQLite 和模拟加密器中复现了旧财务表单覆盖及无法解密后密文丢失，并确认分享缺少版本检查。以下为整改后的当前状态，不再将修复前问题列为待办：

| 领域 | 当前保护及验证 |
| --- | --- |
| 卡片录入 | 提交、草稿、队列身份支持重试与并发去重；事务提交后才清理已消费草稿和队列。档案编辑检查内容及图片版本。 |
| 财务 | 交易、费用、估值在事务内比较完整内容版本，保护修改与删除；相同毫秒和 SQLite 文本日期均有真实数据库回归。保存冲突保留输入。 |
| 分享 | 版本覆盖基本资料、条目、章节、排序与媒体引用；并发只能提交一份完整结构。旧草稿保留来源版本，冲突保留页面输入和文件，失败清理自身上传。 |
| 凭据 | 内置、自定义、代理及旧 Azure 凭据暂时无法解密时，普通设置保存保留密文；明确替换或清除仍生效。覆盖安全存储不可用及仅保存旧 Azure 密钥的配置。 |
| 代理 | 认证、TLS、环境规则、网段绕过、系统候选、逐次重定向分流与私有 Header 清除有本机回归；主动文本测试显示脱敏线路结果。 |

历史复现证据保留在忽略目录 `logs/assessment-20261103-*`；前轮整改为 380 项模块测试、26 项定向界面测试及追加 4 项 AI 复测。前轮日志为 `logs/v1.5.1-reliability-*`，这些结果不替代本轮完整验收。

## 本轮结构整理

| 位置 | 处理与理由 |
| --- | --- |
| AI 设置 | 合并三套内置服务的 Endpoint、模型、密钥表单和草稿组装；加载、保存共用公开设置合并。`use-ai-settings-requests` 负责模型列表与连接测试的取消、过时响应和结果状态，页面组件负责配置编辑。 |
| 设备凭据 | 依据同一服务清单读写内置服务密文，去除每家重复实现；保留“未填写即不修改”的语义和旧 Azure 迁移。移除已无差异的 `modelField` 间接层。 |
| 分享媒体 | 封面和背景共用 `share-media-service` 的保存和清理；Server Action 保留事务、版本和导航编排。 |
| 分享文案 | 字段和公开类型迁入共享领域模块，生成、清洗、JSON 修复集中到服务；路由保留 HTTP 边界。补齐离页取消到主请求和格式修复，取消不得落入文案兜底或再次重试。 |
| 冗余代码 | 删除没有调用的统计日期时间格式化器和无效的财务内部币种参数；视图切换和默认工作区读取辅助改为内部实现。没有因文件较长而拆分成熟的核算或数据库规则。 |
| 发布流程 | PAC 测试加入正式源码验收；发布工作流上传已有构建清单，避免产物与来源信息脱节。 |
| 文档 | 本版说明合并为一份当前变更及验收摘要；同步双语 README、路线图、功能指南、签名指南和资料出处，修正仍指向旧版的“当前”说明。历史版本记录继续保留。 |

源码检查没有发现必须删除的整套孤立业务模块；仅被导入为默认组件或从入口文件使用的代码不当作死代码。数据库建表、恢复校验与旧格式支持具有不同职责，本轮保留其现有边界，不合并成新的迁移方案。

## 依赖安全审计

用户授权后，`npm audit --json --registry=https://registry.npmjs.org` 查询当前公告：31 项中等级、0 项高危、0 项严重，涉及生产及开发依赖。31 是受影响包节点数，不是 31 个不同漏洞；根公告为 `minimatch` 的 [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)。原始结果为 `logs/v1.5.1-review-audit.json`。

公告描述攻击者控制 glob 模式且 `optimizationLevel >= 2` 时的放大与资源消耗问题，修复版本为 11.0.1。源码审阅未发现收藏输入直接作为 glob 模式的入口；ZIP 导出使用明确文件项，构建匹配模式由仓库配置提供。这是对本项目可达路径的判断，不证明所有传递依赖都不受影响。

`npm audit` 提供的多项自动修复建议会跨主版本或降级构建、Lint 和表格依赖。本轮不盲目执行 `audit fix --force`，也不将旧版调用方强制覆盖到 minimatch 11；保留已锁定依赖和高危发布门槛，后续随上游兼容修复处理。本次未将中等级风险描述为已消除。

完整验收首轮发现展示流程仍以按钮可见文字核对返回焦点，与既有图标入口要求不一致。已改为检查焦点准确返回具有“查看大图”无障碍名称的按钮，保留焦点断言；定向展示流程通过。新增离开分享编辑页取消 AI 请求的界面测试也已通过。
