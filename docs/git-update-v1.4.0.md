## 建议提交正文

```text
新增寻卡工作流和紧凑首页收藏概览。

- 首页统一展示估值、卡片状态与收藏概览，支持筛选、按需整理及撤销。
- 跨站查询提供卡淘、eBay、130 Point 入口，关键词支持保存、复用、批量删除及 CSV 导出。

- 提供新卡入藏、绑定搜索、更换、关联收藏查看、反向心愿入口及状态撤销。
- 按收藏恢复心愿草稿，按窗口会话恢复筛选与位置，区分提交失败和刷新失败。
- 分离组合与财务聚合，保留独立对照测试；共享导出快照、并发限制及取消清理。
- 删除旧计划接口、重复待整理读取、关键词商品/价格/研究功能及无用样式。
- 同步双语 README、使用说明、数据规范、路线图与发布文档。
```

## 数据与交付边界

- 寻卡使用四张扩展表，完整 v1.3 基础格式扩展前保存快照；恢复先扩展暂存副本。目标数量在 `ScoutWishDetails` 中保存。
- 关键词只保存查询文本及心愿关系。没有商品、价格、研究记录、自动更新或到价提示。
- 整理后的 `/api/collection-management` 仅处理首页待整理和摘要设置；心愿写入统一使用 `/api/scout`，概览读取统一使用 `/api/home-overview`。
- 财务规则沿用当前模型，缺失金额和汇率不按零处理；保留冻结旧实现作为独立对照。
- 本次工作未执行 Git 提交、推送或创建标签。提交后可按项目惯例创建 `v1.4.0` 标签，发布文件单独作为版本附件。
