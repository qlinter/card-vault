## 2026-11-07 版本内更新

- 删除保护：确认页记录档案、图片、交易、费用、估值和关联记录的版本，在同一事务中核对并删除；发生变化时保留数据并返回详情页，需核对最新内容后重新确认。
- 证书号匹配：精确证书号与最近同主体候选独立查询，精确匹配优先展示，按卡片 ID 去重，仍最多显示五项；仅填写证书号也会触发检查，不阻止合法的独立实物录入。
- 图片校验：JPG、PNG、WebP 保存前完整解码，最多 8000 万输入像素；拒绝损坏、截断和超大像素文件，合法原图字节保持不变。所有使用公共上传入口的卡图、封面、背景及识别图片遵循相同规则。
- 未备份状态：成功读取当前收藏库的备份设置且无记录时显示“当前收藏库尚无成功备份记录。”；加载中、读取失败或无桌面备份接口时不误报，首次成功备份后切换为最近备份状态。

本次不加入新用户体验设计，不修改数据库结构，不迁移或重写既有收藏、财务和图片，历史损坏图片不自动处理。沿用 v1.5.2 数据库与备份格式。

本次安装包 `card-vault-1.5.2-setup.exe`、便携包 `card-vault-1.5.2-portable.zip` 及构建／校验清单已重新生成并通过完整发布验证，沿用现有 v1.5.2 GitHub Release 与下载入口。

## 本版功能与修复

- 收藏回顾：从统计页进入并保留当前范围，按年／月及购入／录入口径自动切换数据，无切换动画。年视图按月、月视图按自然周展示活动；支持临时调整标题和最多六张代表卡片，不保存回顾历史。
- 回顾长图：标题旁直接生成并下载 PNG，默认排除私密卡片并重新计算统计；不输出财务与私人备注。页面和长图共用统计定义及活动分桶。
- 沉浸式赏卡：从展示“浏览”或回顾的赏卡入口进入。提供暗室聚光、白盒美术馆、暖纸典藏、月光展厅四种风格；支持构图、灯光、画幅、顺序／随机、首图／全部、1–3600 秒间隔、缩放、旋转及展馆独立全屏。柔和切换默认启用并尊重减少动画偏好；设置可保存，退出恢复原页面。
- 版式与字体：同级文字和同类控件遵循公共规范；统计范围为小号状态，收藏回顾与查看卡片并排，组合分析紧邻组合总览。
- AI 设置：删除自定义配置改用内联确认并恢复焦点，删除后继续编辑，无需重启。

## 审查与调整

- 检查路由、界面组件、领域服务、桌面存储、初始化、测试和发布脚本之间的依赖；保留已有功能和设计规范。

- 删除 52 条已无运行时代码引用的文案，移除已失效的回顾选择状态样式；保留现有视觉设计。
- 移除未发布的回顾保存模型、建表和增量升级路径。回顾按当前资料计算，新数据库不创建 `CollectionRecap`；已有额外表不自动修改或删除。
- 移除早期 Scout 表结构扩展、单卡关系转换、估值来源转换，以及寻卡、心愿和分析历史的一次性清理脚本、页面入口与缓存清理。启动、恢复和页面访问不再修改这些历史数据。
- 强化架构检查：除了循环依赖和服务端／客户端边界，还检查本地导入是否指向存在的模块。
- 同步中英文 README、应用内说明、版本摘要、当前功能指南和文档索引。发布说明只描述最终行为；开发过程中的变更保留在开发记录中。
